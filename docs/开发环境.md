- **管线**：仓库 `tools/audiogen.py`（Python 纯合成，零采样零版权；依赖 numpy/scipy/soundfile，全局 Python 3.10 @ `D:\py` 均已可用，soundfile 0.14.0 本次 pip 装好）。
- **产物**：SFX → `assets/audio/sfx/*.wav`（44.1k/16bit/mono）；BGM → `assets/audio/bgm/*.ogg`（Vorbis/立体声/无缝循环）。样张在 `docs/音频样张/`（含 mp3 预览副本）。

- **坑 ①**：本机 libsndfile 1.2.2 一次性喂 40s+ 立体声给 OGG/MP3 编码器会**栈溢出**（0xC00000FD）——必须用 `sf.SoundFile` 分块写（脚本内 `_sf_write_chunked`，5s 一块）。
- **坑 ②**：pwsh 命令行里传中文路径/参数会被 GBK 搞乱——跑管线统一用 `workdir=项目根` + 纯 ASCII 相对路径（`python tools/audiogen.py --demo`），输出重定向落盘再读。

### 关键约定与坑

- **坐标约定**：`Vector2i(x=列, y=行)`；棋盘 `grid[行][列]`；行 0 为最上行。
- **场景化绑定**：三场景 UI 已迁移为真实场景节点，脚本用 `%唯一名` 绑定——编辑器内**重命名/移动节点安全，删除节点才会断引用**。动态部分（49 颗棋子、K 线蜡烛）运行时生成，挂在编辑器可见的容器下（`BoardLayer`/`Chart`），拖容器整体移动。
- **K 线图脚本**：`scenes/market/kline_chart.gd`（独立脚本，场景内 Chart 节点挂载；内嵌类无法被序列化，勿移回）。
- **PowerShell 5.1 编码坑**：含中文的 `.ps1` 脚本必须存成 **UTF-8 with BOM**，否则 `powershell -File` 按 GBK 读、中文路径全乱码（tools/rename_scene_nodes_v2.ps1 有 BOM 先例）。
- **外部改 tscn 的守卫**：编辑器/游戏运行时文件被外部修改后，edit 工具会报"file changed since read"——重读再改即可，不是真冲突。
- **用户拖动不生效的排查顺序**：① 场景是否 Ctrl+S 落盘（对比磁盘 offset）② 游戏窗口是否为保存后重开的实例。运行中实例不会热更新布局。
- **tests/_bind_backup**：历史迁移残留，可删；`assets/art/` 图标与头像产物已入库，**勿整目录删除未提交产物**（有 artgen.py 误删先例，2026-10-10 日报事故②；当日已由美术会话重建并补回 `.gdignore`）。
- **GDScript 格式串**：字符串里字面 `%` 必须写 `%%`，否则 `%s` 等占位符会静默不被替换（sim_test check 标题踩过：`"≥50%"` 导致输出 `[%s]` 原样）。
- **后台长任务输出**：pwsh 后台 job 的 stdout 会被截断，大输出一律 `... | Out-File -Encoding utf8 "$env:TEMP\xxx.txt"` 落盘再 `Get-Content` 读；退出码用 `Write-Output "exit=$LASTEXITCODE"` 紧跟管道后取（否则拿到的是 Out-File 的）。
- **$env:TEMP 实际值**：`C:\Users\Acer\AppData\Local\Temp`（用户目录是 Acer，别按用户名猜路径）。
- **sim_test 重生循环模拟**：4 轮 × 12h 游戏时长 ≈ 真实 6 分钟，后台跑落盘；节内采样一律用**本轮相对时间**（`t - round_start`），t 是绝对时间。
- **编辑函数时防"尾巴残留"**：用 old_string 替换函数体时确认 old_string 覆盖到函数末尾，否则旧函数尾部会拼到新函数上（game_state.gd 踩过：debug_set_line 尾巴挂到 debug_set_rebirth 导致 Parse error: Identifier not declared）。
- **Godot 4.7 class_name 注册**：新建 `class_name` 脚本后必须跑一次 `--headless --path . --import`，否则全局类缓存不含新类——其他脚本引用会报 "Identifier not declared"（GameTalents/TalentsPanel/GameSkills 均踩过）。
- **多 Godot 实例并发**：两个 godot 进程同时跑（后台 sim + 前台回归）会争 `.godot` 缓存，某一方挂起假死——测试请串行。
- **PowerShell 管道字符串**：`"$s: 文本"` 会把 `$s:` 解析为作用域变量报错，写 `"${s}: 文本"`。
- **--check-only 快速定位 Parse error**：`godot --headless --check-only --script <文件>` 秒级定位行号，比整场景跑一轮快得多；注意项目开了"警告即报错"（如 Variant 推断、原生方法撞名 get_class）。
- **录屏取证流程**（UI 动画问题）：opencv 抽帧（每 0.5s）→ 平均亮度滤黑帧 → 3×3 网格拼图定位时段 → 关键 2s 内 0.05s 密集抽帧 → 裁棋盘区放大拼条。逐帧对比"块在哪/多大/什么颜色"三要素。
- **GitHub 大文件下载**（国内网络）：直连 release 会被限速到 KB 级（1.19GB 预计 12 天）；用镜像 `https://gh-proxy.com/<完整 GitHub URL>`（~260KB/s）。Windows curl 必须加 `--ssl-no-revoke`（默认 schannel 吊销检查失败 `CRYPT_E_NO_REVOCATION_CHECK`）。
- **Godot 导出模板**：资产名带版本前缀 `Godot_v4.7.2-stable_export_templates.tpz`（不带前缀 404）；tpz=zip，解压后把 `templates/` 目录改名为**编辑器完整版本串**（steam 版 = `4.7.2.stable.steam`）放到 `%APPDATA%\Godot\export_templates\`，名字不匹配会报找不到模板。
