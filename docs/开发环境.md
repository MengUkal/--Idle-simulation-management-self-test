# 开发环境笔记

> 本文件记录本项目的环境事实与工作约定，随仓库走，供人和 AI 助手随时查阅。

## Godot 引擎

| 项目 | 值 |
| --- | --- |
| 版本 | 4.7.2.stable.steam（ed1daf0bf） |
| 可执行文件 | `F:\SteamLibrary\steamapps\common\Godot Engine\godot.windows.opt.tools.64.exe` |
| PATH | **不在 PATH 中**，命令行需用完整路径 |
| 渲染器 | GL Compatibility（Windows 下驱动 d3d12） |
| 拉伸模式 | canvas_items / expand |
| 导出模板 | 未安装（导出成品前需从官网下载 4.7.x 的 tpz） |

常用命令行：

```powershell
# 无头导入/校验工程（CI 或脚本验证用）
& "F:\SteamLibrary\steamapps\common\Godot Engine\godot.windows.opt.tools.64.exe" --headless --path "F:\放置测试\挂机放置增量rpg" --import
```

## 版本控制

- 仓库已初始化（master 分支），`.godot/` 缓存目录被 `.gitignore` 排除。
- 仓库本地身份：`dev <dev@local>`（未设全局 git 身份；如需改成自己的名字：`git config user.name "你的名字"`、`git config user.email "你的邮箱"`）。

## 分工约定

- **助手（程序实现）**：工程结构、代码实现、技术方案、测试验证。
