## 1. 现状盘点（系统长在哪些既有件上）

| 既有件 | 证据 | 装备怎么用它 |
| --- | --- | --- |
| **Mods 修饰符层** | `autoload/mods.gd`：MULT/ADD 键表 + `recompute()` 按来源段聚合（职业→种族→天赋→巅峰） | 装备 = **追加一个来源段**（遍历已穿戴词条 → 贡献 `_mult/_add`），架构零改动 |
| **掉落出口** | 战斗赏金结算（吉尔/精华）；层卡先例（首杀古树掉落，`balance.gd` FLOOR_3_LEVEL_REQ 注释） | 装备掉落挂在**层守/精英/古树首杀**结算处 |
| **数据表模式** | `data/talents.gd` / `skills.gd` / `paragon.gd`（class_name 表 + get_node_def） | 新建 `data/equipment.gd`（基础件表 + 词条池 + roll 范围） |
| **存档模式** | `save_manager.gd` SCHEMA_VERSION=5，v2~v5 兼容规则成熟 | v6 = 背包/穿戴字段，旧档缺省空背包天然兼容 |
| **UI 模式** | 天赋/巅峰面板已场景化（%唯一名绑定） | 装备面板照抄骨架 |
| **资产管线** | artgen.py 图标管线；音效池（SFX 25+3 BGM） | 装备图标生成变体；掉落/穿戴/太古音效 |
| **验证体系** | equipment_test 新建；sim_test 乘区断言 | 词条表标注 mult/add 归属，模拟同步 |

## 2. 设计决策点（☐ 拍板清单——排版的主料）

### D1 定位与范围
- ☐ D1.1 词条作用域：**战斗向为主**（推荐：消除伤害/弱点/精华/赏金/步数）还是含挂机向（收入/训练费）
- ☐ D1.2 每件词条数：**≤3 条**（推荐，暗黑拆解 D4 教训：掉落阅读成本）／4 条／5 条
- ☐ D1.3 品质档：**4 档**（推荐：普通 1 条 / 优秀 2 / 稀有 3 / 传奇 3+固定特殊）／3 档／5 档
- ☐ D1.4 词条 roll：**每条 3 档**（推荐，社区 T1~T7 太重）／5 档／连续值

### D2 部位与栏位
- ☐ D2.1 部位数：**5 部位**（推荐：武器/护符/护甲/行囊/徽记——贴合世界树设定可改名）／4／6
- ☐ D2.2 武器是否分职业专属：**不分**（推荐，7 职业共用降低池子膨胀）／分
- ☐ D2.3 同名装备可重复掉落：**可**（推荐，roll 不同）／每局唯一（D2 式）

### D3 掉落
- ☐ D3.1 掉落源：**层守必掉 1 件 + 精英 30% + 古树首杀保底稀有**（推荐起步组合）／宝箱格
- ☐ D3.2 定向掉落表：**要**（谁掉什么写进怪物表，暗黑拆解提案 B）／全池随机
- ☐ D3.3 保底（Pity）：**不需要**（推荐，层守必掉已兜底）／N 件不出稀有必出

### D4 词条池与特殊词条
- ☐ D4.1 首发词条池规模：**12~16 条**（推荐，覆盖现有多数 MULT/ADD 键 + 步数/连锁）／20+ 条
- ☐ D4.2 传奇词条（规则改写类，暗黑 D3 教科书）：**E2 再做**（推荐，E1 先纯数值）／E1 就要
- ☐ D4.3 太古词条（1.5 倍、只能发现不能打造、专属音效）：**要**（推荐，成本低爽感高）／缓
- ☐ D4.4 条件词条（"满血时…"）：**不做**（推荐，D4 官方砍掉的对象）

### D5 背包、穿戴与打造
- ☐ D5.1 背包：**容量 30 + 一键分解换精华**（推荐，分解口回填训练线货币循环）／无上限
- ☐ D5.2 洗练：**账单制锁 1 洗 1，成本递增**（暗黑 D4 式）／不洗练（roll 不满意就分解）
- ☐ D5.3 洗练/强化货币：**吉尔**（推荐，给吉尔开消耗口）／精华／新货币
- ☐ D5.4 穿戴生效：**即时重算 Mods**（推荐）／战斗开始时生效

### D6 与大系统的咬合
- ☐ D6.1 重生时装备：**保留**（推荐，果实体系已够狠）／一并重置
- ☐ D6.2 层卡：维持"通行证"定位，**不带词条**（推荐，职能分离）／层卡也吃词条
- ☐ D6.3 图鉴（Codex 模式：传奇提取即学会、无限次用）：**E3 再议**（推荐）／E1 就要
- ☐ D6.4 命名：机制名先定（英文键），世界观名交世界观会话（轻背景板宪法）

## 5. 风险与纪律（开工时生效）

1. **乘区纪律**：词条表每条标注 mult/add 键名，E1.6 模拟断言同步——防止"词条×天赋×巅峰"乘区爆炸（全部现有键已枚举于 mods.gd:7-8）。
2. **池子膨胀**：首发 ≤16 条，新词条走增补拍板。
3. **多会话并行**：装备面板/存档/Mods 多文件会碰 project.godot（音频总线事故教训），开工前后 diff。
4. **数值门槛**：词条数值必须过 sim_test（击杀带宽 6~8/8 的既有验收线不回退）。
