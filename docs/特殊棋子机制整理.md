# 特殊棋子机制整理（参考：开心消消乐）

> 来源：[小米游戏中心·特效组合技攻略](https://game.xiaomi.com/viewpoint/64855802_1638970416099_13) 等公开攻略整理，2026-10-09。
> **状态：✅ 2026-10-09 拍板方案 B（全套）并已实装。** 简化项：直线方向不随交换方向变化（横4连=清行、竖4连=清列）；魔力鸟被波及时直接消失不触发；死局重洗会丢失特效。详见 `scripts/match3/match3_board.gd` 头部注释。
> 用途：决策"是否引入特殊棋子系统"的参考材料。开心消消乐与 Candy Crush 同源，规则通用。

## 1. 三种基础特效的生成规则

| 特效 | 生成条件 | 触发效果 |
| --- | --- | --- |
| **直线特效** | 4 个同色连成一线消除 | 清除一整行或一整列（分横/竖两种方向） |
| **爆炸特效** | 同色组成 **L 形或 T 形**（合计 ≥5 个且非直线） | 清除以自身为中心的 3×3 范围（9 格） |
| **魔力鸟** | **5 个同色排成一条直线**消除 | 与任意普通棋子交换 → 清除全场该颜色棋子 |

细节：
- 生成位置通常是玩家交换落点的那颗棋子。
- 直线特效的方向由消除排列（或交换方向）决定。
- 特效棋子**被任何消除波及时会自动触发**，触发可以连锁引爆其他特效。

## 2. 组合技（交换两个特效棋子时触发）

| 组合 | 效果 |
| --- | --- |
| 直线 + 直线 | 十字消除（一行 + 一列同时） |
| 直线 + 爆炸 | 以爆炸为中心的 **3 条行/列**同时清除 |
| 爆炸 + 爆炸 | 大范围爆炸（约 5×5） |
| 直线 + 魔力鸟 | 全场该颜色棋子**全部变成直线特效**并触发 |
| 爆炸 + 魔力鸟 | 全场该颜色棋子**全部变成爆炸特效**并触发 |
| 魔力鸟 + 魔力鸟 | **全场清空**（游戏最强效果） |

## 3. 套路价值

- 高分核心 = 攒特效 → 组合引爆 → 连锁滚雪球。
- 魔力鸟是节奏器：留着等场上目标颜色多时再打。

## 4. 移植到本游戏的映射（P&D 式战斗：消除=攻击）

| 开心消消乐机制 | 本游戏战斗含义 |
| --- | --- |
| 直线特效（清 7 格） | 一次 7 格的成排攻击，各格独立结算克制（弱属性整行 = 巨额伤害 + 大量精华） |
| 爆炸特效（9 格） | 高伤范围攻击 |
| 魔力鸟清同色 | **弱属性色魔力鸟 = 超级弱点打击**（全场弱属性块 ×2 伤害 ×2 精华）——留鸟等刷弱属性色，策略深度显著提升 |
| 组合技 | "大招时刻"，配合赏金结算的爽点 |
| 特效连锁 | 连锁加成（+20%/波）已有，自然兼容 |

## 5. 实装成本评估（诚实版）

- **棋盘逻辑**：形状检测（区分 4 连/5 连/L/T）、特效标记（棋盘数据结构从"元素编号"扩展为"元素+特效"）、触发传播链、组合判定 → 逻辑复杂度约为当前 2~3 倍。
- **UI**：特效棋子需要视觉标记（占位方案：边框/星标 + 触发闪烁）。
- **测试**：形状检测、传播、组合表都要新增用例。
- **工期**：与 M2 核心本体相当或略小（全套）；简化版（仅直线+爆炸）约为一半。

## 6. 分期建议

- **一期**：直线 + 爆炸（含被波及自动触发、连锁）——约 80% 的爽感、40% 的复杂度。
- **二期**：魔力鸟 + 组合技（6 种）——招牌大招 + 深度。
- 魔力鸟与弱属性克制的化学反应是本游戏独有卖点（开心消消乐没有"弱点"概念）。
