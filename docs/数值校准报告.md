## 4. 关键锚点速查

- 收入：`0.06 × 1.10^(Lv-1)` × 收入线 × 果实 × 修饰符；**离线 = 该值 ×60% ×≤8h**
- 献金：`UPGRADE_BASE × COST_GROWTH^(Lv-1)`（费用增速 > 收入增速 → 越练越慢的墙）
- 重生：门槛 `40 + 8×轮数`；果实 `fruits_for_level`（幂 1.8 / 除 4）
- 层门槛：二层 Lv.10 / 三层 Lv.50+层卡 / **四层 Lv.60+层卡**
- 步数：`10 + 0.5×Lv`（Lv.60 = 40 步）
