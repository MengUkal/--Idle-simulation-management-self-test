# 完整版试玩验收清单（v1.0 候选）

> 使用 `build/IdleTreeRPG.exe`（111.4MB+）逐项验证。旧存档会按 D5 拍板自动删除重开。

## 1. 启动与角色

- [ ] 标题画面显示世界树立绘 + 开场动效；BGM（一层曲）响起
- [ ] 「新的开始」→ 角色创建：9 种族 × 7 职业可点选，特性预览正确
- [ ] 随机 / 默认按钮可用；确认后进入主界面

## 2. 主界面

- [ ] 四按钮状态：天赋（0 点）/ 巅峰（需 Lv.60，置灰）/ 设置 / 撤退可用
- [ ] 献金升级、训练线三按钮数值正确（含职业/种族折扣）
- [ ] 层间按钮显示「前往第二层（需 Lv.10）」并置灰

## 3. 战斗（一层）

- [ ] 三消核心：交换、消除、掉落、连锁（分波可见）
- [ ] 特殊棋子：直线/爆炸/魔力鸟生成与引爆
- [ ] 技能栏：充能计数随消除增长；满 1 格后可释放；效果符合职业表
- [ ] 需要瞄准的技能（战士/圣骑士/游侠）：进入瞄准 → 点棋盘生效 → 再按取消
- [ ] 怪物：一层六怪 + 树根守卫；音效（消除/连锁/击杀/胜负）
- [ ] 撤退：弹确认 → 留下/返回主界面都正常

## 4. 成长链路

- [ ] 升级 → 技能点 +1（天赋按钮数字变化）
- [ ] 训练线三线可升（费用含折扣）
- [ ] 里程碑 Lv.2/4/6/8 精华奖励

## 5. 二层（Lv.10）

- [ ] 前往第二层；翠枝回廊六怪 + 守林古树（精英 10% 出现率）
- [ ] **首杀古树** → 层卡掉落提示（toast：守林古树承认了你，它吐出一枚「苍干栈道层卡」）
- [ ] 二层达成时登层 toast 显示（枝务厅通知：您的登层签证已下发）

## 6. 重生（Lv.40）

- [ ] Lv.38 世界树低语引导（一次）
- [ ] Lv.40 献上等级按钮亮起 → 确认弹窗（得失明细）→ 果实结算 → 重开
- [ ] 重生后：果实计数、训练折扣、天赋点保留、层卡保留

## 7. 巅峰（Lv.60）

- [ ] 巅峰按钮解锁；三板块（二/三需前一板块传奇点亮）
- [ ] 节点购买/退还（免费）；效果在战斗/收入中体现

## 8. 交易所（Lv.15）

- [ ] K 线行情、三标的买卖、手续费（矮人减半）
- [ ] Lv.15 前进入交易所：锁定面板显示侏儒名言与解锁等级

## 9. 设置与持久化

- [ ] Esc 设置页：全屏/窗口切换、音量滑条（**挂 BGM 听效果**）、震屏/伤害数字开关
- [ ] F11 快切；关闭游戏重进：进度/设置/层卡/巅峰全部保留
