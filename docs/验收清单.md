# 完整版试玩验收清单（v1.1）

> 使用 `build/IdleTreeRPG.exe` 逐项验证。旧存档按 D5 拍板自动删除重开。
> v1.1 增补（2026-10-11）：装备 / 天赋 / 巅峰 / HP / 伙伴（P1 后）/ 离线 / 三四层 / 属性面板验收项；⭐ 为拍板文案彩蛋检查项。

## 1. 启动与角色

- [ ] 标题画面显示世界树立绘 + 开场动效；BGM（一层曲）响起
- [ ] 「新的开始」→ 角色创建：9 种族 × 7 职业可点选，特性预览正确
- [ ] 随机 / 默认按钮可用；确认后进入主界面

## 2. 主界面

- [ ] 按钮齐备且状态正确：献金 / 训练×3 / 层间 / 冒险 / 交易所 / 天赋 / 巅峰 / 装备 / 属性 / 设置 / 撤退
- [ ] 天赋按钮显示可用技能点；巅峰按钮 Lv.60 前置灰；装备按钮随首件掉落点亮
- [ ] 献金升级、训练线三按钮数值正确（含职业/种族/装备折扣）
- [ ] 层间按钮显示「前往第二层（需 Lv.10）」并置灰

## 3. 战斗（一层）

- [ ] 三消核心：交换、消除、掉落、连锁（分波可见）
- [ ] 特殊棋子：直线/爆炸/魔力鸟生成与引爆
- [ ] **玩家 HP 条**：棋盘下方显示；受怪物攻击时扣血
- [ ] **怪物蓄力条**：随步数消耗递减，归零发动攻击并重置
- [ ] 技能栏：充能计数随消除增长；满 1 格后可释放；效果符合职业表
- [ ] 需要瞄准的技能（战士/圣骑士/游侠）：进入瞄准 → 点棋盘生效 → 再按取消
- [ ] 怪物：一层六怪 + 树根守卫；音效（消除/连锁/击杀/胜负/技能就绪）
- [ ] **战败**：HP 归零 → 本局收益作废 → 退回主界面，持有物不丢
- [ ] 撤退：弹确认 → 留下/返回主界面都正常

## 4. 成长链路

- [ ] 升级 → 技能点 +1（天赋按钮数字变化）
- [ ] 训练线三线可升（费用含折扣）
- [ ] 里程碑 Lv.2/4/6/8 精华奖励
- [ ] 首件装备掉落 → 背包与装备按钮点亮

## 5. 二层（Lv.10）

- [ ] 前往第二层；翠枝回廊六怪 + 守林古树（精英 10% 出现率）
- [ ] **首杀古树** → 层卡掉落提示 ⭐（toast：守林古树承认了你，它吐出一枚「苍干栈道层卡」）
- [ ] 二层达成时登层 toast 显示 ⭐（枝务厅通知：您的登层签证已下发）

## 5.5 三层（Lv.50 + 层卡）

- [ ] 镇风桩机制：先制弱点封印 → 连击护盾 → 桩劲蓄力 → 狂暴 → 根性，大横幅提示明显
