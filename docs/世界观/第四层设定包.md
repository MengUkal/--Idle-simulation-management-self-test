## 4. 数值参考稿（非拍板，供工程侧参考）

二层→三层实装倍率：常驻 HP 约 ×2.4（120~220 → 380+）、赏金约 ×1.9（18~32 → 55+）、精英 HP ×2.2（500 → 1100）、精英赏金 ×1.67（120 → 200）。
按同倍率外推四层：常驻 HP 900~1500、赏金 100~190；精英（千瓣祭主）HP 约 2400、赏金约 330。
注意：四层处于 Lv.60+ 巅峰成长期，练度曲线含天赋/巅峰加成，最终数值以工程侧模拟为准。
