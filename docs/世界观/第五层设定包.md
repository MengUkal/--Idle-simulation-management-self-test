## 3. 层守与祝福体制

授权链随第五层补全（轻背景板：只做设定，不约束精英机制）：

| 层 | 层守 | 身份 |
| --- | --- | --- |
| 一层 | 树根守卫 | 树自己长的门房 |
| 二层 | 守林古树 | 编外层守（登记在枝务厅） |
| 三层 | 镇风桩 | 商会发工资，树给编制 |
| 四层 | 千瓣祭主 | 比枝务厅老，名册上没有它 |
| 五层 | 瞭望鹰 | 不是雇的，也不是编外的——它是树的一只眼睛 |

**暗线推进**：层守的身份一层比一层接近树本身。到瞭望鹰这里，"祝福体制"的谜底开始露头：所谓层级，可能不是枝务厅定的，是树长的。
