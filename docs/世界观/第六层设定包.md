## 3. 层守机制

- 星望者：守望者定位（与瞭望鹰同型——**先制·封印 + 蓄力窗 + 根性**，无狂暴）
- 工程标定：Lv.85 门槛 AI 战败 8/8（守望者硬门槛）；Lv.90 均伤打掉 43%

## 4. 暗线推进

层守身份链：门房 → 编外 → 编制 → 无名册 → **树的一只眼** → **替树等一个日子的守望者**。
星望者望着彩虹桥——它在等什么，树不肯说。（彩虹桥 = 终局钩子，点满巅峰后预告已实装。）
