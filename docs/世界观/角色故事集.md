# 角色故事集（种族与职业的来历）· 已拍板

> 地位：圣经 §12 角色术语表的故事面。回答一个问题：这座树上，这些人是从哪来的。
> 纪律：直白版风味纪律。平实叙述，短句，无破折号，不配口头禅，不抖机灵。每篇都咬住既有设定，机制效果在故事里有出处。
> 用途：图鉴、角色创建界面扩写、成就文案的母本。UI 不强制展示；轻背景板宪法照旧。

在树根之街，报出身要报两样：种族和行当。种族是娘胎里带来的，行当是自己选的。以下十六篇，就是这座树上形形色色的来历。

## 种族九篇

**人类**：人类在树干中段安家最晚，爬得却最快。枝务厅的册子上，第一批登层签证的持有者就是人类。他们没有专长，所以什么都肯做，哪里都敢去。

**精灵**：最早在枝桠间住下的族群之一，天生带一点精华的亲和。他们话少，攒得快，翠枝回廊的辉羽蝶认识每一个路过的精灵。

**矮人**：尼达维勒商会的主人一族。根下开炉三千年，炉心矿是他们挖的，交易所的秤是他们校的。商会规矩第一条：秤不准，就关门。

**巨人血裔**：巨人倒下的时候，血渗进了树根。很多年后，土里站起来一些人，个子高，力气大，反应慢半拍。街上的老人说，那是骨头里的记性。

**兽人**：兽人不是爬上来的，是打上来的。他们沿着根须一路打穿魔物，打到哪里就住到哪里。攒钱不是他们的长处，认赏金的眼力却是。

**侏儒**：矮人分家时带走工具的那一支。侏儒造的东西小而精，如今街面上大半的训练器械出自他们手笔，便宜，耐用。

**巨魔**：从树根之街的码头苦力做起的族群。皮糙肉厚，干得久，别人收工了他们还在干。巨魔不急，树能活千年，急什么。

**暗精灵**：住在树荫背光面的族群，做账比谁都干净。他们的规矩只有一条：影子里的钱也是钱，还更安静。

**高等精灵**：精灵里最早学会看弱点的一支，旧年月里被称作奥术贵族。如今名声主要靠精确撑着：他们出手之前，怪物的标签已经看完了。

## 职业七篇

**战士**：树根之街最老的行当。啃根兽开始渗上来的那年，街口就站上了第一代战士。功夫没有花巧，全是从挨打里练出来的，所以学得慢。

**法师**：克制环是树的法则，法师是把它读透的人。他们出手前先看属性，专挑弱点下手，精华顺手就进了口袋。

**盗贼**：商道栈道上长大的一群，最懂什么叫连锁。一环扣一环，环环有油水，出手快，落袋也快。

**牧师**：献金体制里少见的温和行当，替街坊做祝祷、记账、守夜。进项稳，步子稳，是街坊最放心孩子去干的职业。

**圣骑士**：从守夜人里选出来的规矩人。什么都练一点，什么都不冒尖，但枝务厅的考评表上，圣骑士的名字没出过错。

**游侠**：不肯待在街上的行当，整天在树上跑野路。步子多，路子野，越往后走，连锁的功夫越深。

**术士**：和树做交易的行当。他们从树那里借来远超常人的力量，抵押品是平时的进项。据说签过约的人，连结出的果实都更沉。枝务厅不推荐，也不禁止。

## 使用说明

1. 每篇都对应机制效果：巨人血裔的力气与迟缓、术士的借力与代价、矮人的秤与手续费，故事即数值的出处；
2. 职业故事把七职业安放进"献金爬树社会"的行当体系，与层卡（树根之街/翠枝回廊/苍干栈道）同一世界观；
3. 进 UI 位（图鉴、创建界面扩写、成就）需另拍板，本集先做设定母本。
