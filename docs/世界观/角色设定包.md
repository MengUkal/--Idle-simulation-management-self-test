## 4. 术语冲突解决：矮人 / 侏儒 / 尼达维勒

**问题**：圣经 §6 写的是"尼达维勒商会＝侏儒商行"；新种族把矮人与侏儒拆成两族，占位文案里两族都挂尼达维勒。

**提案**：尼达维勒住两族，分工明确——**矮人是商会的主人**（管钱，所以手续费减半），**侏儒是工匠支系**（管造，所以训练便宜）。随拍板回填圣经 §6（"侏儒商行"改"矮人商行"）与资料笔记用语。
