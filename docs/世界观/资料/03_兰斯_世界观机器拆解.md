# 世界观资料 03 · 兰斯系列（世界观机器拆解）

> 地位：世界观三基石之一（2026-10-10 拍板），并已拍板**基调=兰斯式黑色幽默**（荒诞皮＋严密骨）。
> 来源：《RANCE》系列（AliceSoft，1989《Rance 1》–2018《Rance X》）公开设定综述。
> **约定**：只取世界观工程学方法论与喜剧配比，原作成人内容不进入本项目；原作年表数字各资料版本略有出入，本笔记**取结构、不考据数字**。

## 1. "一个大"工程学：40 年、10 余部、一个大陆

- 全系列共用同一个舞台"大陆（The Continent）"，世界观**只增不推翻**。
- 历史用**三大历史事件**锚定，此后所有作品都在这三根桩子上挂新内容：
  1. **圣魔教团的崛起与崩坏**——千年前的魔法超大国，留下遗迹与technology遗产；
  2. **AL 教团的创立**——信仰与秩序体系，大陆的"默认背景板机构"；
  3. **魔王与魔物的出现**——外部威胁与内部体制（魔王系统）同时确立。
- 每部新作 = 往同一个世界加一块拼图：新国家、新势力、新历史段落，旧设定从不回收。

### 对接本项目

- 名词一旦写进游戏就是**资产**：树根之街、翠枝回廊、火晶石……后续内容反复引用，永不改名（除非用户拍板改）。
- 本项目也用"锚点事件法"建小年表：见[世界观设定 §3](<../世界观设定.md>)。

## 2. 授权层级：魔王 → 使徒 → 魔物

- 魔王把力量分给使徒，使徒再批量造出魔物——**力量沿食物链逐级授权**，每一级都有明文规则（繁殖方式、寿命、弱点、等级上限）。
- 好处：全世界的敌人天然长成**一棵亲缘树**；打败下层杂兵可以顺藤摸瓜逼出上层，叙事自动生成。
- 原作还有"等级制"的明文规则（人类等级存在上限、技能等级体系），数值系统本身是设定的一部分。

### 对接本项目

- 世界树的"**祝福体制**"可同构：树心 → 层守（各层精英）→ 层内魔物。魔物为什么出现在树根？——啃根兽的血统自上而下渗下来（轻背景板：一句话设定即可，不约束怪物表）。
- 精英怪（树根守卫/守林古树）天然是"层守"层级，未来加层就有位置放新层守。

## 3. 势力卡模板：每国一张卡

原作五势力各自一张卡、绝不重样：

| 势力（原作） | 政体 | 一句刻板印象 |
| --- | --- | --- |
| 利萨斯王国 | 王政，人治 | 正统王道国，主角的主场 |
| 泽斯 | **魔法力决定阶级的种姓制** | 与本项目"等级即阶级"异曲同工的极端版 |
| 赫尔曼帝国 | 军国 | 大陆军国，面子大里子虚 |
| 自由都市地带 | 商业松散联盟 | 有钱没主权 |
| JAPAN | 锁国武士文化 | 格格不入但谁也吞不掉 |

**模板字段**：政体 / 文化底色 / 经济支柱 / 军事 / 邻国关系 / 一句刻板印象。

### 对接本项目：层卡

每个楼层一张"层卡"，字段照搬：**主题 / 生态 / 经济 / 守门规则 / 一句刻板印象**——第三层以后照模板量产。现有两层与提案见[世界观设定 §5](<../世界观设定.md>)。

## 4. 喜剧皮 + 严密骨的配比（基调的官方说明书）

- 表层：主角是无赖，剧情满是无节操吐槽；
- 底层：政治、宗教、经济的关联网严密得像百科全书，**笑点精确踩在设定上**。
- 配比经验：
  1. **正剧推进时完全严肃**——严肃才衬得出后面那一脚刹车；
  2. 笑点集中在两处：**角色吐槽**（角色冲世界发牢骚）与**制度荒诞**（世界本身不合理，但人人习以为常）；
  3. **不拿自己的设定开玩笑**——设定是圣域，拿"世界的不合理"开玩笑。
- "献金换等级"本身就是制度荒诞的完美素材：没人问为什么钱能换祝福，因为**问的人都被收了手续费**。

## 5. 可偷的招（对接清单）

1. 三大历史事件锚定年表法——小成本建立历史纵深。
2. 授权层级让怪物有亲缘树——精英/层守的位置自动腾好。
3. 层卡/势力卡模板——内容量产的流水线。
4. 笑点规范——吐角色、吐制度，不吐设定、不吐玩家。
