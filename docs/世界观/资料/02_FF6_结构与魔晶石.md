# 世界观资料 02 · FF6（双世界结构与魔晶石）

> 地位：世界观三基石之一（2026-10-10 拍板）。借"钱与魔法的世界感"和"中期翻页"的结构。
> 来源：《最终幻想VI》（SQUARE，1994，SFC）游戏内容与公开资料综述。本项目货币"吉尔(G)"即 FF 系列通用货币，已在 M1 拍板沿用。

## 1. 世界结构：平衡世界 → 废土世界

- **前半·平衡世界**：加斯特拉帝国（榨取幻兽之力造魔导装甲）vs 回归者（抵抗军）vs 幻兽界（魔法之源）三方角力。
- **中场翻页**：反派凯夫卡扰动三大斗神像，大陆被物理撕裂——**世界地图当场变成另一张地图**。
- **后半·废土世界**：凯夫卡君临废墟作乐，幸存者一年后各自在废土上重建生活，玩家把散落的同伴一个个找回来。

### 结构要点

1. **世界本身是剧情角色**：地图、城镇、音乐随剧情整体翻页，玩家"认识的世界"被没收一次。
2. **反派真的赢了中场**：不靠时光倒流回滚，玩家在既成事实的废土上继续活——绝望之后是更扎实的希望。
3. **翻页前后同一批地点两种面貌**：内容复用的极致（同一座城，繁荣版/废墟版）。

### 对接本项目：重生（M4）叙事模板

- 重生 ≠ 读档，而是"**世界翻一页**"：每轮重生树入"世界之冬"，文案/街景描述换一版（轻背景板下只做文案彩蛋，不动场景资源）。
- 同一层的"繁荣版/冬装版"描述对，是远期文案库的低成本扩容方向。

## 2. 魔晶石体系：力量被做成了商品

- 幻兽"存在本身就是魔法"；帝国捕获幻兽榨取其力。
- 幻兽死后结晶为**魔晶石**——装备它就能习得其魔法，还能召唤。
- 要点：魔法从"血统天赋"变成**有产地（幻兽界）、有供应链（帝国）、有市场价（晶石）的可交易资源**。

### 对接本项目

- **元素精华 / 世界树的果实**的"资源化"叙事原型：精华是"树的记忆结晶"，果实是"轮回的存档"。
- 交易所三标的（火晶石/風羽绢/生命露）可以直接沿用这套"产地→供应链→市价"的讲法。

## 3. 吉尔与帝国经济学

- 吉尔（G）贯穿 FF 系列，玩家对"打怪赚钱→花钱变强"有肌肉记忆——本项目挂机循环的货币心理学基础。
- 帝国线展示了**战争经济学**的写法：魔导装甲要预算、俘虏幻兽要经费、打仗本质是烧钱——"钱驱动世界"的现实感。
- 名场面方法论：**用"不搭调的场景"制造记忆点**——在正剧中场插一场完整歌剧、在末世插一段赛艇。反差越大，记忆越深。

## 4. 凯夫卡：小丑式反派塑造

- 出场是宫廷小丑/幕僚：言语轻佻、举止滑稽，行事却暴虐——**幽默皮包暴力骨**。
- 名台词"笑，笑！尽情地笑吧！"；最终形态是天使般的扭曲躯体——荒诞与恐怖同体。
- 敌意不靠狰狞造型，靠"彬彬有礼地作恶"的错位感。

### 对接本项目

- 若未来需要"世界树的代言层"出现反派/压力源，走**"彬彬有礼的荒诞"**路线：官僚、印章、服务窗口——比魔龙更贴合本项目的黑色幽默基调。

## 5. 群像方法论

- 14 名可操作角色、双主线（蒂娜=血统之谜 / 洛克=过去之罪），每人一段"一场戏讲完的过去"。
- 配角不需要完整弧光，需要**一个立得住的记忆点**（一句台词、一个动作、一场戏）。

### 对接本项目

- 轻背景板定位下，NPC 按此标准量产：层卡里每个 NPC 只写"一句话身世 + 一句口头禅"。

## 6. 可偷的招（对接清单）

1. **中期翻页**：世界状态可变——重生文案的"冬装版"。
2. **力量商品化**：精华/果实的供应链叙事模板。
3. **名场面思维**：一场戏一个记忆点（交易所暴涨暴跌的"股神时刻"就值得一场戏）。
4. **小丑反派**：彬彬有礼的荒诞感 > 狰狞脸。
