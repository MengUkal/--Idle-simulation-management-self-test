# 世界观资料 01 · 北欧神话（九界与诸神黄昏）

> 地位：世界观三基石之一（2026-10-10 拍板）。世界树是本项目的舞台本体，本篇是"树的官方说明书"。
> 来源：公版原典综述——《诗体埃达》（尤其《女先知的预言》Völuspá）与《散文埃达》（斯诺里·斯图鲁松，13 世纪）。各译本细节略有出入，本笔记**取结构与意象，不考据字句**，用于创作参考。

## 1. 世界结构：一棵树，三层九界

世界树 **尤克特拉希尔**（Yggdrasil，意为"奥丁的马"——奥丁曾把自己倒吊树上九夜换取卢恩智慧，后人戏称那是在"骑树"）是一棵白蜡树，**九界都挂在它身上**。

## 2. 诸神黄昏（Ragnarök）事件链

> 核心气质：**结局早已写好，众神照样天天备战。** 宿命感与荒诞感同体，这就是黑色幽默的原生土壤。

1. **预兆**：芬布尔之冬——连续三年不见夏天；道德崩坏，兄弟为钱互相动手（原典真的这么写）。
2. **天象**：狼吞掉太阳与月亮；大地震动，束缚松脱——芬里尔魔狼挣脱锁链，世界蛇掀起海浪上岸，洛基掌舵幽灵船纳吉尔法（用死人指甲造的船）载着亡者军团而来。
3. **点火**：火之国巨人苏尔特举着燃烧巨剑，把世界从头烧到尾。
4. **决战**：奥丁被芬里尔吞掉（其子维达撕狼报仇）；托尔与世界蛇同归于尽（毒发走九步倒下）；几乎全员阵亡。
5. **沉没与再生**：世界沉入海底，随后**重新升起，绿意盎然**；幸存的神重返平原，藏在世界树里躲过末日的一男一女（利芙与莱夫特拉希尔）走出树洞，重新繁衍人类；棋盘金器自己下棋——新世界从旧世界的心愿里长出来。

### 对接本项目：重生系统（M4）的叙事模板

- **一轮重生 = 一次小型"世界之冬"**：把等级献还给树 → 树入冬 → 结出果实 → 新芽再爬。
- 玩家不是诸神，是**躲进树洞里的那两个人**——每次都从树根重新出发，但带着果实（上一次世界的记忆）。与已拍板的果实机制完全同构。
- "世界树见过无数次冬天"——转生次数（rebirth_count）的神学解释，现成的。

## 4. 可偷的招（对接清单）

1. **层序 = 树的解剖学**：根 → 干 → 枝 → 冠 → 顶，每层都有原典对应界域，第三层以后不愁主题。
2. **重生 = 小型诸神黄昏**：冬天/果实/新芽的意象链全部现成。
3. **神也付费解锁**：奥丁献眼换智慧——"献金制"的神话级背书，黑色幽默的核心支柱。
4. **现成命名一大把**：松鼠情报商、啃根毒龙、侏儒商会、女武神考勤员。
