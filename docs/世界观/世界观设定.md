## 1. 一句话世界

> **世界是一棵树。树管一切，但树不说话——替树说话的机构收钱。**

展开说：世界树就是世界本身——根扎着死者的地，冠托着神的地，人住在树干中段，不上不下，正好方便交税。人们向树献上吉尔换取祝福（等级），等级够高才能住得更高一层；平时工作挣吉尔（挂机）；攒够了诚意把等级连本带利还给树，换一颗果实（重生）。树的业务范围很广，但它本人从未出现过。

## 2. 创世（一段讲完）【已拍板：巨人遗骸派】

冰与火在虚空的鸿沟里相遇（原典：金伦加），先凝出了血肉——原初巨人。巨人走完了他的一生，倒下；他的脊柱不肯腐烂，向上生长，长成了世界树。根是他的骨，枝是他的指，树皮上的纹路是他的掌纹。所以楼层里偶尔挖出的大骨头别问是谁的——问就是地基。树不需要人照料：它自己扎根，自己结果，自己发明了手续费。

> 留档未采纳：灰烬自燃派（世界从火灾余烬里长出来，"没人浇水，全靠自燃"）。

## 4. 祝福体制（为什么钱 = 等级）

- **树的法则**【lore·已定】：钱是"凡人对树的诚意"的法定计量单位。为什么？古往今来如此——费用曲线（×1.15）是树写的，别问，问就是旨意。
- **枝务厅**【已定·机构】：代树收金、代金发福、办登层签证。非树非人的官僚机构，各层设支部，盖章狂魔。**不是反派**——它不邪恶，它只是流程。
- **工作条款**【已定 2026-10-10】：挂机就是**工作**，收入就是工钱。树根之街的居民靠双手挣吉尔，不做额外包装。
- **精华条款**【已定（已拍板机制的世界观说法）】：战斗中溢出的元素之力凝成**元素精华**——树的记忆结晶，侏儒称之为"能喝的卢恩"。
- **果实条款**【已定（M4 机制的世界观说法）】：把等级连本带利献还，树结下一颗**世界树的果实**——果实是轮回的记忆。每轮重生就是一次"**世界之冬**"【已定】：树入冬、结果、发新芽。世界树见过无数次冬天，而挨过冬天的都记性好。
- **登层签证**【已定】：等级达标才能上一层（现规则：Lv.10 进二层）——不是树拦你，是你的签证没批下来。

1. 本圣经**不约束**：数值、系统机制、玩法设计。玩法先行，文案让路；设定与玩法冲突时，**改设定**。
2. 本圣经**只提供**：命名、氛围文案、新内容立项的背景板（层卡模板）。
3. 机制名与文案名分离（§7 纪律）。
4. 与《游戏设计文档》的关系：那边管玩法，这边管氛围；两边互加链接。
5. 本圣经内一切"提案"进游戏前（改 UI 文案、加 NPC 名）必须过拍板问答——协作规则不变。
