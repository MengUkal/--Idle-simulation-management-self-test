# 挂机放置增量RPG · 设计文档 v0.1

> 本文档是游戏的唯一设计事实源：记录已拍板的设计决策、当前数值与待定问题。
> 分工：内容/数值/玩法/设定由用户拍板，助手负责整理成文并实现。

## 1. 一句话概念

在世界树的世界里，人们向树献上吉尔（G）换取等级（祝福），等级达标便能登上更高一层——挂机赚钱、献金升级、逐层登树。

## 2. 世界观与设定（用户提供）

- **主题**：日式奇幻。
- **舞台**：一棵世界树。世界以"层"划分，玩家从第一层（树根）出发。
- **核心规则**：人们通过花钱提升自己的等级；只有等级达标，才被允许从第一层进入第二层。
- **升级的设定包装**【已拍板 2026-10-09】：向世界树**献金**，换取更深的祝福（即升级）。
- **舞台命名（助手拟，可改）**：第一层 = "树根之街"。
- **世界观事实源**【2026-10-10 拍板】：[`docs/世界观/世界观设定.md`](<世界观/世界观设定.md>)（圣经 v0.2）——创世/年表/祝福体制/层卡/命名库/文案风味归它管；玩法与数值仍以本文为准。

## 3. 核心循环

```
挂机收入(吉尔/秒) ──> 累积吉尔 ──> 向世界树献金升级
      ▲                                │
      └──── 等级提升 → 收入提高 ────────┘
                                       └──> 等级达标 → 解锁下一层（世界观钩子）
```

- 挂机时玩家的主视觉是"吉尔数字在涨"；主动操作是"献金升级"。
- 消消乐（= 在世界树冒险战斗打怪）是第二条收入来源，M2 加入。

## 4. 经济系统：三种收入来源

| # | 来源 | 形态 | 状态 |
| --- | --- | --- | --- |
| 1 | 挂机收入 | 按时间自动增长 | **M1 实现** |
| 2 | 消消乐（冒险战斗） | 三消（滑动交换）；步数上限随**玩家等级**提高；每次消除=一次攻击；收益与消除表现和怪物种类挂钩 | M2 |
| 3 | 附加玩法（如炒股） | 小游戏提供额外收入 | M3+ |

- **多线成长**：后续扩展方向（收入线 / 战斗线 / 商业线并行），架构上预留。

## 12. 数值模拟结论（tests/sim_test.gd，2026-10-09）

模拟方式：真实 Match3Board 引擎 + 贪心弱属性 AI，用与线上一致的 Balance 公式跑完整循环。

- ✅ 纯挂机 Lv.1→10 = **30.1 分钟**（拍板 30+，达标）。
- ✅ 主动游玩到 Lv.10 ≈ **7 分钟**（约 4 倍速）——符合"消消乐是主动收入主力"的设计意图。
- ✅ 二层成型练度（攻线 ~7 级）击杀率 **65%**；一层 Lv.1 普怪击杀率 88~100%、岩甲龟 25%（保留紧张感）。
- ⚠️ 观察一：裸 Lv.10 零训练线直接进二层，击杀率仅 0~12%——这是预期的"练度门槛"（有层间往返兜底，主动玩家到二层时攻线自然有 6~7 级）；如嫌太狠可下调二层首档 HP。
- ⚠️ 观察二：精英守林古树（500HP）在 Lv.20+攻线10 下仍 0/8——当前版本的天花板怪，属重生/练度扩展前的长期目标；嫌太狠可降 HP 或提出现率。
- 📌 主动 2h ≈ Lv.37，献金费用 1.15^级将在 Lv.38+ 形成明显钱墙 → 正好是 M4 重生系统的设计卡点。

### 12.1 M4 重生循环模拟结论（tests/sim_test.gd 第四节，2026-10-10 数值定稿）

首轮拍板方案（门槛步进 8 + 温和果实 + 双轨）模拟暴露：周期逐轮恶化 134→198→253 分钟（费用墙 ×3.06/轮 vs 线性加成追不上）、古树第 3 轮才 25% 击杀（练度每轮清零）。四组变体对比（base/陡果实/陡果实+攻击轨/完整组合）后用户拍板定稿：**门槛步进 5 + 陡果实公式 + 三轨加成**。

定稿后模拟（定稿规则全真镜像）：

- ✅ 周期收敛：132→143→146→128 分钟，四轮全部落在验收带 90~155 内且不恶化；
- ✅ 古树：第 3 轮门槛练度 5/8 稳定击杀（第 2 轮 1/8 → 第 3 轮跳变，攻击轨是主因）；
- ✅ 体感：果实积累后开局 10 分钟等级 12→16（第 3 轮 vs 首轮），且随轮数继续扩大；
- 📌 第一轮开局体感与首轮持平（果实只有 5 颗，收入 ×1.25）——果实从零积累的数学必然，靠里程碑重发与训练轮衰减补偿。

## 14. M4 重生系统设计【2026-10-10 六项问答拍板】

> 世界树叙事：把等级献还给世界树，换下「世界树的果实」——果实永不失去，越吃越强。

### 14.1 六项拍板结论

| # | 决策点 | 拍板结论 |
| --- | --- | --- |
| 1 | 货币名 | **世界树的果实**（果实永久累计，任何重置不影响） |
| 2 | 重置范围 | **清零**：等级→1、吉尔→0、三训练线→0、献金等级随等级。**保留**：果实累计、交易所持仓（股数）、行情历史（行情引擎是全局时钟，与玩家无关） |
| 3 | 永久加成 | **双轨起步 → 数值定稿三轨**：每颗果实 → 挂机收入 ×(1+5%×果实)、训练费用 ×0.98^果实、攻击效果 ×(1+1%×果实) |
| 4 | 门槛曲线 | **混合 → 数值定稿步进 5**：第 n 轮重生门槛 = 40 + 5×n（首轮 40、二轮 45、三轮 50…）；训练费用另乘 0.95^已重生轮数（NGU 式永久衰减） |
| 5 | 解锁引导 | **Lv.38 首次触墙**（献金钱墙显形）弹世界树引导文案；主界面「献上等级」按钮 Lv.40 前锁定并显示进度，Lv.40 亮起 |
| 6 | 挑战模式 | **本轮不做**，M4.5 再议 |

### 14.2 数值定稿（2026-10-10 第二轮问答：模拟对比 → 用户拍板）

> 首轮拍板原案模拟暴露两个缺口：门槛步进 8 使费用墙每轮 ×3.06，周期逐轮恶化（134→198→253 分钟）；练度每轮清零导致古树第 3 轮才 25% 击杀。四组变体模拟对比后用户拍板「完整组合」：

| 项 | 定稿值 | 说明 |
| --- | --- | --- |
| 门槛步进 | 40 + 5×轮数（40/45/50/55…） | 原 +8，周期收敛的决定性变量 |
| 果实公式 | `floor(((等级-30)/4)^1.8)` | Lv.40→5、45→10、50→18、55→27、60→38 颗 |
| 加成三轨 | 收入 +5%/颗 · 训练费 -2%/颗 · 攻击效果 +1%/颗 | 攻击轨为新增（古树关键） |
| 训练轮衰减 | 每轮 ×0.95（永久） | 不变（首轮拍板） |
| 模拟成绩 | 周期 135→151→144→127 分钟收敛 | 第 2 轮起全部进验收带 |
| 古树节奏 | 第 2 轮 38% → **第 3 轮 75% 稳定击杀** | 【拍板】长线荣耀目标定位 |

### 14.3 验收线（数值定稿版）

1. **周期**：每轮重生到下一门槛 90~155 分钟（1.5~2.5h），且趋势收敛不恶化；
2. **体感**：果实积累到 30+ 颗后（约第 3 轮），重生开局 10 分钟等级 ≥ 首轮同期 +5 级；
3. **古树**：守林古树（500HP）在第 3 轮门槛练度下稳定击杀（≥5/8）——承原路线图「1~2 轮」微调为「2~3 轮」，用户拍板。
