# 挂机放置增量RPG · 设计文档 v0.1

> 本文档是游戏的唯一设计事实源：记录已拍板的设计决策、当前数值与待定问题。
> 分工：内容/数值/玩法/设定由用户拍板，助手负责整理成文并实现。

## 1. 一句话概念

在世界树的世界里，人们向树献上吉尔（G）换取等级（祝福），等级达标便能登上更高一层——挂机赚钱、献金升级、逐层登树。

## 2. 世界观与设定（用户提供）

- **主题**：日式奇幻。
- **舞台**：一棵世界树。世界以"层"划分，玩家从第一层（树根）出发。
- **核心规则**：人们通过花钱提升自己的等级；只有等级达标，才被允许从第一层进入第二层。
- **升级的设定包装**【已拍板 2026-10-09】：向世界树**献金**，换取更深的祝福（即升级）。
- **舞台命名（助手拟，可改）**：第一层 = "树根之街"。

## 3. 核心循环

```
挂机收入(吉尔/秒) ──> 累积吉尔 ──> 向世界树献金升级
      ▲                                │
      └──── 等级提升 → 收入提高 ────────┘
                                       └──> 等级达标 → 解锁下一层（世界观钩子）
```

- 挂机时玩家的主视觉是"吉尔数字在涨"；主动操作是"献金升级"。
- 消消乐（= 在世界树冒险战斗打怪）是第二条收入来源，M2 加入。

## 4. 经济系统：三种收入来源

| # | 来源 | 形态 | 状态 |
| --- | --- | --- | --- |
| 1 | 挂机收入 | 按时间自动增长 | **M1 实现** |
| 2 | 消消乐（冒险战斗） | 三消（滑动交换）；步数上限随**玩家等级**提高；每次消除=一次攻击；收益与消除表现和怪物种类挂钩 | M2 |
| 3 | 附加玩法（如炒股） | 小游戏提供额外收入 | M3+ |

## 5. 成长系统

- **MVP 单线**【已拍板 2026-10-09】：等级即收入——升级既提高挂机收入，又推进登层门槛。
- **多线成长**：后续扩展方向（收入线 / 战斗线 / 商业线并行），架构上预留。

## 7. M1 数值基准【已按拍板调整 2026-10-09】

| 项 | 值 | 说明 |
| --- | --- | --- |
| 初始吉尔 | 0 G | |
| 挂机收入 | 0.06 × 1.10^(等级-1) G/秒 | 指数成长、慢于费用成长 → 越练越慢 |
| 献金费用 | 10 × 1.15^(等级-1) G | 首次献金（升 Lv.2）= 10 G |
| 到二层门槛用时 | 纯挂机约 30 分钟 | "攒够即献金"最优路径估算 |
| 自动保存间隔 | 10 秒 | 另有关窗即存 |

节奏明细：首升约 2 分 47 秒，Lv.9→10 约 4 分钟。此节奏是**不玩消消乐**的底线体验；M2 上线后消消乐是主动收入的主要来源。

## 10. 技术架构摘要（助手负责）

- Godot 4.7 / GL Compatibility / PC 横版 1920×1080（canvas_items 拉伸）。
- 自动加载单例：`EventBus`（信号总线）→ `GameState`（数据唯一持有）→ `Economy`（收入引擎）→ `Market`（交易所行情）→ `SaveManager`（存档）。
- 数值全部集中在 `data/balance.gd`（数据驱动，改数值不改逻辑）。
- 存档：`user://save.json`，schema v3（v2 字段 + 交易所持仓与行情状态，兼容读旧档），10 秒自动保存 + 关窗即存。
- M1 的 UI 由代码构建（`scenes/main/main.gd`），美术阶段再迁移到场景文件。
- 冒烟测试：`tests/balance_test.gd`（数值公式）+ `tests/match3_test.gd`（三消逻辑）+ `tests/sim_test.gd`（数值/机制模拟试玩），均无头可跑。
- 内置修改器：`scenes/dev/dev_panel.gd`，主界面与战斗界面按 **F1** 开关（仅 debug 构建加载，release 导出自动消失）：加吉尔/精华、设等级、快进挂机收入、训练线直调、层间传送、清档。

- **装备/配装**：冒险掉装影响各模块速度，配装卡阈值是深度所在 → 远期装备系统。

## 12. 数值模拟结论（tests/sim_test.gd，2026-10-09）

模拟方式：真实 Match3Board 引擎 + 贪心弱属性 AI，用与线上一致的 Balance 公式跑完整循环。

- ✅ 纯挂机 Lv.1→10 = **30.1 分钟**（拍板 30+，达标）。
- ✅ 主动游玩到 Lv.10 ≈ **7 分钟**（约 4 倍速）——符合"消消乐是主动收入主力"的设计意图。
- ✅ 二层成型练度（攻线 ~7 级）击杀率 **65%**；一层 Lv.1 普怪击杀率 88~100%、岩甲龟 25%（保留紧张感）。
- ⚠️ 观察一：裸 Lv.10 零训练线直接进二层，击杀率仅 0~12%——这是预期的"练度门槛"（有层间往返兜底，主动玩家到二层时攻线自然有 6~7 级）；如嫌太狠可下调二层首档 HP。
- ⚠️ 观察二：精英守林古树（500HP）在 Lv.20+攻线10 下仍 0/8——当前版本的天花板怪，属重生/练度扩展前的长期目标；嫌太狠可降 HP 或提出现率。
- 📌 主动 2h ≈ Lv.37，献金费用 1.15^级将在 Lv.38+ 形成明显钱墙 → 正好是 M4 重生系统的设计卡点。
