## 4. 本次自动推进的环境备忘（已回填开发环境.md）

- Godot tools 版是 GUI 子系统程序：PowerShell `&` 直调不等待、`$LASTEXITCODE` 拿不到——用 `Start-Process -Wait -PassThru -RedirectStandardOutput/Error` 或 `cmd /c`。
- 截屏钩子旗标不统一：battle=`--capture-debug`，market=`--capture-market`（传错旗标场景会一直跑不退出）。
- 含中文路径的 .ps1 必须 UTF-8 with BOM（再次踩实，已有条目的实证补充）。
