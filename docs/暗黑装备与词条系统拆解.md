# 暗黑破坏神装备与词条系统拆解 · 参考整理

> 2026-10-11 整理。用途：为远期装备系统（NGU 提炼 §11 已预留"冒险掉装、配装卡阈值"方向）收集设计底稿。性质同《[智龙迷城玩法拆解.md](<智龙迷城玩法拆解.md>)》——**参考材料 + 提案，未拍板不实装**。
> 引用来源见文末；D2 机制取自游戏开发社区的完整逆向整理，D3 取自暴雪官方说明，D4 取自赛季机制指南。公式细节未实测复核。

## 1. 三代一句话演进（先立骨架）

| 代 | 装备哲学 | 一句话 |
| --- | --- | --- |
| D2 (2000) | **随机词缀海** | 生成管线决定一切：基础类型 → 品质 → 前后缀池 roll；毕业靠海量掉落 + 词条知识 |
| D3 (2012) | **传奇词条定义 build** | 传奇之力改变技能形态（build-defining），套装 2/4/6 件绑定玩法；Ancient/Primal 做 roll 质量分层 |
| D4 (2023+) | **掉落简化 + 打造承担复杂度** | 掉落时词条少而直白（传奇 3 词条），深度后置到 Tempering/Masterworking 等确定性打造 |

## 2. D2 的装备生成管线（随机词条的经典架构，来源①）

**核心概念**：`TC(财宝阶层) → 物品类型 → 物品品质 → 词缀`，物品落地瞬间全部属性定型。

- **品质检测序**（从稀有到普通逐级尝试）：`Unique > Set > Rare > Magic > Superior > Normal > Low`；MF（寻魔）只作用于这一步，且**收益递减**（MF 250%→1000%，暗金实际只 +102%）。
- **词缀门控**：每条前后缀有 `alvl（词缀等级）`，由掉落怪的 `mlvl` 决定物品 `ilvl`，再折算出可用词缀上限——**高级词条天然锁在高级怪物背后**；词缀与物品类型有严格的可用矩阵。
- **品质数量差**：Magic ≈ 1 前 1 后；Rare = 3~6 条（名字由词缀拼成）；Unique/Set = 固定词条（设计产物，不随机）。
- **降级兜底**：选中 Unique/Set 但不存在对应物（或怪等级不够）→ 掉 3 倍耐久 Rare / 2 倍耐久 Magic——**保底不空手，但明确降档**。
- **稀有度权重**：同品质内部还有 rarity 权重表（SoJ 的掉率被更常见的暗金戒指稀释——"想打 SoJ 就去打打不出其他暗金戒指的怪"）。
- **赌博/NPC**：赌博词缀上限挂钩角色等级（clvl−5/+4）；NPC 货 ilvl=clvl+5——等级即视野。
- 其他：无形（5%，数值更强但不可修）、插孔/符文之语（基础装 × 镶嵌 = 第二套词条系统）、每游戏唯一 Unique。

> **可提取的骨架**：①词条池按等级门控 ②品质=词条数量档 ③同品质内稀有度权重 ④保底降级而非空手 ⑤"目标怪定向刷"（掉落表与怪物绑定）。

## 3. 词条系统的设计学（跨代不变量）

1. **词条数量 = 身份**：品质档的第一表达不是数值高低，而是"能带几条词条"。
2. **roll 范围**：同一条词条有 min~max（社区称 T1~T7 档），"满 roll 毕业装"是长线追求；**百分比词条与绝对值词条分开处理**（D3 中 Ancient/Primal 不提升百分比词条，防失控）。
3. **加算 vs 乘算**：伤害类词条大量是加算区（D4 后期把乘算集中到少数系统），平衡模拟必须分清乘区——**我们 sim_test 的乘区纪律直接适用**。
4. **条件词条**："满血时+10% 对精英伤害"这类词条 D4 赛季4 被大幅削减——**评估成本高的词条是掉落阅读负担**（来源④官方整改思路）。
5. **定向 vs 随机**：词条池必须可控（定向打造/洗练），否则 RNG 挫败感压过惊喜感——D4 把"改词条"做成确定性的账单制（材料越滚越贵）。

## 4. D3 的贡献：传奇之力与 roll 分层（来源②）

- **传奇词条 = build 定义力**：传奇装备的价值不在数值高，而在"改变技能规则"（如某技能获得 X 效果、某资源翻倍）——**词条从'数值'升级为'规则'**。
- **Ancient / Primal**：同为传奇，roll 值更高（Primal = 全满值）；Primal 需通关大秘境 70 才解锁掉落。
- **官方设计哲学（原文）**："Primal 为已经基本毕业的玩家提供继续玩下去的兴奋点，而**不让人觉得是必需品**"——终局追逐层的定位参考。
- 套装（2/4/6 件触发）是 D3 的 build 主载体，但套装绑定玩法过强导致"毕业=穿套装"的单一解（后期赛季用"无套装加成"活动反向鼓励散件）——**套装是强药，剂量要慎**。

## 5. D4 的贡献：复杂度后置 + 确定性打造（来源③④）

赛季4 "Loot Reborn" 的装备重做（官方整改，持续生效）：

- **掉落侧做减法**：传奇只带 3 词条、稀有 2 词条，砍条件词条、提词条数值；掉落总量减少但单件价值提高——"**多打怪，少分类**"。
- **打造侧做加法**（S.T.E.A.M 流程，顺序敏感）：
  - **Tempering（锻刻）**：按部位开放词条类别池，给装备加第 4/5 条；次数有限、可修复。
  - **Enchanting（附魔）**：锁定一条重洗一条，金币成本递增——概率逐步变贵。
  - **Aspect（传奇精华）**：传奇之力与装备解耦——从掉落中**提取**进 Codex of Power（图鉴库，无限次使用，保留最高 roll）；"刷到 = 学会"，装备只是载体。
  - **Masterworking（精工）**：25 级每级全词条 +1%，每 4 级暴击强化某一条（颜色递进），终段 +50% 随机词条可重掷。
  - **Greater Affix（太古词条）**：1.5 倍数值，**只能被"发现"，不能洗出来**；掉落有专属音效与光柱——*惊喜的仪式感*。
  - **Transfiguration（终变）**：末期高风险强化（~10% 毁词条），可用道具换保守结果——风险自选。

> **可提取的骨架**：①掉落阅读成本要低（词条少而直白）②"收集到能力"比"刷到那一件"友好（Codex 模式）③打造 = 把 RNG 换成账单 ④顶级词条保留"只能发现"的惊喜位 ⑤高风险步骤必须可退。

## 6. 与本游戏的映射（现状盘点）

**已具备的"词条土壤"**：修饰符层（角色系统）、三训练线、天赋树（职业词条）、巅峰 32 节点（含代价型词条）、层卡（掉落物先例：首杀古树掉层卡）、模拟器乘区纪律、图鉴母本（角色故事集注明"图鉴/成就母本"）。

**装备系统若立项，PAD/暗黑给到的接口**：战斗掉落（目前只有吉尔/精华）→ 装备落点自然在**层守/精英/古树首杀**；词条作用对象自然是**消除/技能/训练线**（呼应训练费-2%/颗果实的既有词条形态）。

## 8. 明确不采用（避免重新讨论）

- **耐久度/修理/无形**：纯摩擦，与挂机放置的轻松基调冲突。
- **鉴定（未辨识掉落）**：早期神来之笔，现代设计共识为摩擦；我们掉落即明示。
- **交易行/金币经济**：单机买断形态，无玩家间经济。
- **赛季 ladder**：无运营结构；"层卡/重生轮"已承担节奏重置职能。
- **套装 2/4/6 绑定玩法**（远期慎入）：单解性强，若做建议只到 2/3 件的小剂量。
