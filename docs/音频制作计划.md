## 0. 现状一句话

游戏目前**零音频**：无音频资产、无 AudioStream 代码、无 AudioManager。核心循环（挂机/三消战斗/训练线/交易所/重生）已全部跑通，事件总线信号齐全——音频是纯增量层，可以"听总线接线"的方式接入而**不动现有游戏逻辑**。

## 1. 设计原则（已定夺，除非用户反对）

1. **程序化合成，零采样**：全部音效与音乐由 `tools/audiogen.py` 用 numpy/scipy 合成生成——无版权风险、参数即风格、改完重跑全套一致更新。与美术方案 A（artgen.py 程序化图标）同一哲学。
2. **风格基调**【v2 按拍板升级】：日式奇幻 × 北欧神话皮 → 暖木质感 + 钟琴/竖琴色；听感对标 **FF6 / DQ 等经典 JRPG 与东方 Project**——和声加 6/7/maj7 色彩、旋律主题动机化 + 16 分音符跑动、编曲做 A/A' 段落层次。全部落 D 调家族（交易所 E 小调自成一角），连击也和声。
3. **挂机游戏不吵**：UI 音量 -9 dB、核心反馈 -3 dB 峰值、BGM 峰值 -6 dB；每帧触发的事件（吉尔数字滚动）**不做声音**；10 秒一次的自动存档**默认无声**。
4. **音效优先于音乐**：手感反馈（交换/消除/特殊技/结算）是三消玩法的心跳，P0 先行；BGM 二首随 P0，第三首（交易所）P1。

## 4. 技术方案（已定夺）

### 4.1 管线与产物

- 脚本：`tools/audiogen.py`（`tools/.gdignore` 已有，Godot 不导入）。
  - `python tools/audiogen.py --list` 列目录；`--demo` 出样张到 `docs/音频样张/`；`--all` 全量出正式资产；`--only <id>` 单个重出。
- 目录：`assets/audio/sfx/*.wav`（44.1kHz/16bit/单声道）＋ `assets/audio/bgm/*.ogg`（Vorbis q 默认/立体声）。
- 响度：SFX 峰值 -3 dB（UI 类 -9），BGM 统一 **RMS 0.125**（`BGM_TARGET_RMS`，2026-10-11 实测三首相差最大 24% 后拉齐）——切层/切场景音量不跳变；重生成一遍全套自动一致。
- 环境已就绪：Python 3.10 + numpy + scipy + **soundfile 0.14.0（本次新装）**，无需联网组件。

### 4.2 接入设计（AudioManager autoload，待实施）

- 新增 `autoload/audio_manager.gd`：SFX 播放池（8 个 AudioStreamPlayer 轮转）+ 2 个 music 播放器交叉淡入淡出；Audio 总线分 `Music`/`SFX` 两条，音量独立可调。
- **静音开关**：M 键循环（全开/仅音乐/仅音效/全静），设置存 `user://audio_settings.json`——**不动存档 schema**。
- 接线分两类：
  1. **总线直听（零侵入）**：`level_changed` / `money_not_enough` / `floor_unlocked` / `floor_changed` / `essence_changed` / `line_changed` / `rebirth_performed` 由 AudioManager 自己 connect。
  2. **战斗内显式调用（小改动）**：`swap_ok/fail`、`clear_*`、`special_*`、`combo_chain`、`monster_*`、`battle_win/retreat` 在 `battle.gd` / `match3_board.gd` 现有动画回调处加 `AudioManager.play("id")` 调用；`trade_buy/sell` 在 `market.gd` 买/卖函数各加一行。估算每处 1~2 行，不影响逻辑。
- 实现注意（护栏）：
  - 读档/重生会重放 `level_changed` 等信号 → AudioManager 开局与重生后 0.5s 静默窗口，防止"开机音爆"。
  - `essence_changed` 连发节流（0.5s 最多一响）。
  - 新增音频文件后必须 `godot --headless --import` 注册（美术管线同款坑）。
  - BGM 切换时机：层切换 / 开关交易所面板；战斗场景沿用所在层 BGM 不打断（挂机氛围连贯——拍板项③）。
