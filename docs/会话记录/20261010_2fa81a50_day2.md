# 暗黑 4 天赋/技能树设计整理

## 版本一：经典天赋树（2012~2023 玩家认知的 D4 发布版 1.0）

| 机制 | 设计 |
| --- | --- |
| **一职业一树** | 每职业一棵独立大树，中心为起点向外生长 |
| **节点类型** | ① 普通节点（Minor）：属性小增幅（如 +5% 伤害），1 点；② 重点节点（Major）：更强的条件增益；③ **技能节点**：主动技能本体+升级+强化二选一；④ **关键天赋（Key Passive）**：树末端唯一节点、三选一，**定义整个流派**（选了它，整个 build 围绕它转） |
| **层圈门槛（Gates）** | 树按层圈分节，进入下一圈要求**树上已投入总点数达标**（如 2/6/10/16/23/33 点）——强制你铺量才能深入 |
| **点数** | 1~50 级每级 1 点 + 声望奖励，全级约 58~60 点（点数在“技能等级”与“被动节点”之间**竞争分配**） |
| **洗点** | 可单点退还，也可整树重置（后期收金币）；重置成本随投入增长 |
| **体验核心** | 路径规划——点数有限+层圈门槛，逼你做取舍；Key Passive 是 build 的灵魂 |

## 版本二：技能树 3.0（2026 现行，Lord of Hatred 资料片永久改版）

| 机制 | 设计 |
| --- | --- |
| **被动节点全部移除** | 天赋树里不再有被动属性点（移到装备词缀/传奇威能），点数全部围绕**主动技能** |
| **每个主动技能 = 三条分支** | ① 分支一：通用修正器；② 分支二：另一个独立修正器；③ 分支三：**加成技能变体（Bonus Skill Variant）**——build 定义级的三选一 |
| **技能变体** | 大幅改变技能行为：伤害类型转变（火→冰）、形态改变、资源机制改变——**同名技能因变体不同而完全不同**，变体即 build 身份 |
| **分支按角色等级解锁** | 不再靠铺点数，达到等级自动开放分支（洗点更自由） |
| **点数上限 83** | 深化单个技能而非平均分配 |
| **洗点** | 手动洗点花金币（可预览）；军械库免费存 5 套 build 配置一键切换 |
| **体验核心** | “先选变体，再配装”——变体改变技能标签，牵动装备/词缀联动 |

## 两版对比一句话

> **1.0 = 被动属性的路径规划树；3.0 = 主动技能的分支强化系统。** 它们其实是两个不同系统的名字都叫“天赋树”。
