# ComfyUI 本地部署计划（美术方案 C）

## 目标

## 已实测的环境事实

| 项 | 结论 |
| --- | --- |
| 安装位置 | `F:\AI\ComfyUI`（F 盘空闲 101.4G；C/D 盘不足） |
| 显存 | RTX 3050 Laptop 4096MB → `--lowvram` + SD1.5 + 512×512，单张约 20~40 秒 |

## 实施步骤

1. **装解压工具**（2 分钟）：`winget install 7zip.7zip`，失败则官网单文件 `7zr.exe` 兜底。

3. **下载模型**（5~15 分钟，走 hf-mirror）：日系奇幻向 SD1.5 底模（主选 Anything 系立绘风，备选 DreamShaper 8，出图对比后定）；像素风 LoRA 能找到就加，找不到也不影响——像素化靠后处理保底。
4. **首次启动 + API 验证**（5 分钟）：`--lowvram` 启动为后台常驻服务（127.0.0.1:8188，只在生图时开），curl `/system_stats` 确认 GPU 可用。
5. **写 `tools/gen_asset.py` 管线**：提示词模板（统一风格前缀 + 每只怪的特征描述）→ ComfyUI API 排队 → 轮询取图 → Pillow 后处理（512→128 降采样、32 色调色板量化、纯色背景抠成透明）→ 落盘 `assets/art/monsters/`。
6. **试产 3 张样张 → 你拍板风格 → 批量 14 只**：风格属于内容决策，按分工约定由你过目拍板，我不自作主张。批量完成后接入 battle 界面头像位。
