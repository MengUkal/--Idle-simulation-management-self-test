## 1. 四个候选方向

### 方向 A：M4 重生转生（Prestige）★ 推荐主线
- **为什么是它**：设计文档里早有预案（NGU 模式：重置换永久货币 + 训练需求每轮衰减 + 临时加成转永久）；模拟数据已把卡点指到 Lv.38；当前版本打到二层后**没有长线目标**，重生是放置游戏留存的生命线。
- **要做的事**：设计问答（重生货币叫什么/重置什么保留什么/衰减曲线/解锁门槛 Lv.40?）→ 数值建模 + 模拟器扩展 → 实装 → 二层/古树数值随重生体系重校。
- **验收**：一轮重生 1.5~2.5 小时主动游玩（数值定稿模拟 132~146 分钟收敛）；果实积累后开局肉眼变强；古树在 2~3 轮重生内变得可击杀（第 3 轮 ≥62.5%，2026-10-10 数值定稿拍板）。

### 方向 B：内容扩展 · 第三层
- **是什么**：新主题楼层 + 6 怪 + 精英（沿用翠枝回廊模式），Lv.25~30 门槛，衔接重生体系。
- **为什么靠后**：内容需要用户大量拍板（主题/怪物/数值），且没有重生系统时三层就是"更厚的墙"，价值打折。**建议作为方向 A 的后续奖励层**。

### 方向 C：美术补完 · 怪物头像
- **是什么**：14 只怪物（一/二层各 7）头像从占位升级为真图；路线 B（云 API，注册送额度，几分钱/张）或 C（本地 ComfyUI + SD1.5 + 降采样调色板量化像素化）；顺带统一 UI 皮肤、K 线配色。
- **成本**：B 需注册 + key 配置；C 需装环境 1~2 小时。管线后处理脚本（像素化）两种路线通用，可先写好。
- **性质**：与 A 完全并行不冲突，适合作为"等拍板间隙"的副线。

### 方向 D：体验打磨 + 发布工程
- **是什么**：试玩收集手感反馈调参（特效频率/动画时长）；**安装 Godot 4.7 导出模板**（当前未装，导出成品的前置）；Windows 构建产物 + README/截图，具备发给朋友试玩的形态。
- **价值**：让游戏脱离"开发者机器"流通起来，收集真实反馈——节奏类游戏的长命之本。
