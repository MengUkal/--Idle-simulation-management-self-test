## 1. 伙伴系统（精简版）

### 1.1 循环

战斗击杀 → 概率掉**怪物蛋** → 孵化入住**树根兽栏**（一层街尾设施）→ 图鉴点亮 + 全局小加成 → 重复蛋只计数量 → 设 1 只**看板怪**发动专属被动。

### 1.2 掉落规则（D2）

| 来源 | 掉率 | 蛋内容 |
| --- | --- | --- |
| 常驻怪 | 2% | 本怪蛋 |
| 精英（树根守卫/镇风桩等） | 15% | 本怪蛋 |
| 层守首杀 | 100% | 层守专属蛋（层卡式纪念位） |

蛋品质复用装备四档（粗品/普通/精良/史诗）＝伙伴加成档位：品质每升一档，该伙伴加成 ×2（档位间平滑可调，工程标定）。

### 1.3 伙伴加成（设计原则）

每只伙伴一条**固定小被动**，从怪物特性派生，数值 T1 级（具体值 sim_test 标定）。示例（非定稿）：

| 伙伴（示例） | 看板/常驻加成（提案方向） |
| --- | --- |
| 花粉蛾 | 战斗首波伤害 +2% |
| 岩甲龟 | 受到伤害 -2%（HP 系统上线后生效） |
| 光萤 | 挂机收入 +1% |
| 蜜壶蜂 | 元素精华获取 +2% |
| 岩甲龟/風狼…… | 其余 21 只同规则派生 |

**图鉴奖励（提案）**：每层集齐 6 只常驻 → 该层赏金 +3%；层守专属蛋 = 图鉴特殊页。

### 1.4 看板位（D3）

- 兽栏设 1 个看板位，指定 1 只伙伴**发动其被动**（不重复计算常驻加成）；
- 看板位效果随怪物特性各不相同（收集的意义：挑选全局被动）；
- 世界观：兽栏门口挂看板，看板怪是树根之街的招牌。

### 1.5 命名（D6，已收编）

树根兽栏（设施）/ 怪物蛋 / 看板怪（看板位）/ 驯养执照（枝务厅发放，收服的设定出口：养怪也要证）。

## 2. 生命值系统（核心战斗变更）

### 2.1 循环（变更后）

消块竞速（不变）＋ **怪物蓄力攻击**（新增）＋ 玩家 HP 条（新增）。步数内击杀=胜利；HP 归零=战败（收益作废，D8）。

### 2.2 攻击模型（D7 蓄力条制）

- 怪物表新增字段：`atk`（攻击力）、`speed`（蓄力步数 N）；
- 玩家每消耗 1 步，N 减 1；归零发动攻击并重置；
- 基准：常驻怪 N=5~6（伤害=攻击力的 30~50%）、精英 N=3~4、层守 N=2~3（配合狂暴墙/蓄力窗已有机制）；
- 层守机制包适配：先制=开场立即攻击一次；狂暴墙期间攻击力提升（原减伤墙保留）。

### 2.3 HP 构成（D9 全构成）

`HP 上限 = 基础 100 + 等级 × 成长 + 职业修正 + 装备词条 + 果实/巅峰（可选）`

- 职业修正（提案）：战士 +40%、圣骑士 +30%、牧师 +10%、游侠 0、盗贼 -10%、法师 -20%、术士 -20%；
- 果实/巅峰是否吃 HP：工程模拟定（建议先不吃，避免数值叠爆）。

### 2.4 新词条（进 §1 词条池，编号顺延）

| id | 名称 | 键 | 效果 | 可出部位 |
| --- | --- | --- | --- | --- |
| af_vital | 丰盈 | max_hp | 生命上限 +6%/级（T1~T5） | 头/身/腿 |
| af_regen | 再生 | regen | 每波消除回复 1~3 点（T1~T5） | 戒指/饰品 |
| af_guard | 坚壁 | dr | 受到伤害 -3%/级（T1~T5） | 身/肩/盾 |

> 生命露道具已拍板不做（D10）；回复只靠再生词条/牧师系技能（预留）。

### 2.5 战败（D8）

HP 归零 → 本局赏金/精华不结算 → 退回主界面；持有物（蛋/装备/层卡）不丢。层守战战败 = 层卡不掉（重挑即可）。

## 3. 分期建议（工程侧参考）

1. **P-a HP 系统**（核心变更，先行）：怪物表加 atk/speed → battle.gd 蓄力条与玩家 HP → 新词条 3 条 → 存档 v7 → **sim_test 全量重校**（击杀率/战败率双验收）；
2. **P-b 伙伴一期**：蛋掉落 + 兽栏 + 图鉴 + 常驻加成（依赖怪物表，与 P-a 并行可）；
3. **P-c 看板位**：伙伴 UI + 看板被动结算；
4. E2 远期：进化/洗练/规则型传奇（原预留不变）。

## 4. 接口备忘（给实装会话）

- 怪物表：`{atk, speed}` 两字段；层守机制包不变（攻击数值化即可）；
- Mods 新键：`max_hp`（MULT）、`regen`（ADD）、`dr`（ADD，与狂暴墙减伤同乘区合并）；
- 存档 v6 → **v7**：+伙伴图鉴/兽栏/看板位/玩家 HP 相关；
- 验收新增：各层战败率带宽（放置游戏战败应是"可感知但不挫败"，建议一层 0%、二层 <10%、四层 15~25%——数值工程标定）。
