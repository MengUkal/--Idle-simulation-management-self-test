# TapTap 上架文案（2026-10-13 v1.0）

## 游戏名称
**世界树：挂机三消 RPG**（备选：挂机世界树 / 世界树物语）

## 一句话简介（≤30 字）
消除就是攻击！在六层世界树上挂机、爬塔、刷装备，走过彩虹桥。

## 详细介绍

世界树高六层，从树根之街一直长到云端的星梢。
你在最底下醒来，兜里只有 17 个吉尔。
树说：往上爬吧，祝福明码标价。

【三消就是战斗】
消除方块 = 攻击怪物。连得越多，打得越痛。
打出四连、五连，还会生成直线、炸弹和魔力鸟。
打弱点色的伤害和精华双双倍——看准了再消。

【挂机也在变强】
每秒都有吉尔进账，离线最多结算 8 小时。
睡着的时候，世界树也在替你攒钱。

【六层世界树，层层不一样】
树根之街 → 翠枝回廊 → 苍干栈道 → 落英花冠 → 云顶鹰巢 → 星梢。
每层有专属怪物、专属层守、专属机制：
有的层守给你减伤硬扛，有的往你棋盘里塞障碍，有的干脆遮住你的眼睛。

【装备是三维的】
品级（粗品到史诗）× 词条（洗练出你想要的）× 太古（只能发现，不能强求）。
42 只伙伴图鉴、看板位加成、蛋掉的稀有度——收集党有得忙。

【7 职业 × 9 种族】
战士的破城锤、法师的嬗变、盗贼的偷天换日……
每职业一个专属技能，配种族特性自由组合，重生保留。

【巅峰长线】
Lv.60 解锁巅峰板块，81 点巅峰等你点满。
难度 1~5 指数挑战，每个难度都要再赢一次星望者。
终点是一道红热的桥——星望者替树等了很久的那天。

【其他】
· 单机离线可玩，无强制联网
· 无内购，无体力，无弹窗广告
· 电脑 / 手机数据各自独立
· 手机横屏游玩，建议佩戴耳机
