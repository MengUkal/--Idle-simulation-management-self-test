## 2. 提效方案

### P0-1 修好 Hindsight 记忆层（收益最大，一次配置永久生效）

- **做什么**：创建 `C:\Users\Acer\.hindsight\coding-agent.json`。云模式填 `{"apiUrl": "https://api.hindsight.vectorize.io", "apiToken": "<控制台获取>"}`；不想用云则 `"serverMode": "daemon"` 走本地。
- **为什么第一**：它直接消灭损耗点 #1——会话结束自动回写记忆、新会话自动注入上下文，整理会话的手工提取归档降级为"按需挑重点"，冷启动从"读全套 docs"变成"读记忆注入 + README 索引"。
- **注意**：DeepSeek Harness 是常驻插件，改配置后**重启会话才生效**（apiToken 例外，热读）。本工作区记忆库为 `coding-agent::放置测试`（按工作区根解析，多项目共享一库，符合现状）。
- **验收**：新会话首条 prompt 触发 reflect 注入；`hindsight_sync_status` 返回 synced。

### P0-2 固化统一验证入口 `tools/preaccept.ps1`

- **做什么**：一条命令 = 串行跑全部测试套件（`--script` 类与 tscn 类各自正确调用）+ 场景冒烟 + `--import` 校验 + 可选 `-Capture` 截图取证，输出落盘报告 + 汇总表（PASS/FAIL/断言数）。关键实现点开发环境.md 已备好：Godot 是 GUI 子系统程序，必须 `Start-Process -Wait -PassThru` 取退出码；实例必须串行；含中文路径的 ps1 存 UTF-8 with BOM。
- **为什么**：把损耗点 #4 从"每个会话的手艺"变成"项目的资产"。预验收从半天人工降为一键。
- **验收**：新会话不看文档也能 `tools/preaccept.ps1` 出完整报告；截屏旗标细节被脚本封装，无人再需要记。

### P1-1 会话写范围 + 收尾五步清单

- **做什么**：
  - 写范围默认约定：美术 = `assets/art/**` + `tools/artgen*.py`；音频 = `assets/audio/**` + `tools/audiogen.py` + `docs/音频*`；世界观 = `docs/世界观/**`；主线 = 其余。跨范围先交接后动手。
  - **`project.godot` 单一属主 = 主线**，其它会话一律不改（缺配置走代码兜底，先例 `e19aee0`）；属主每次编辑前后 diff。
  - 会话收尾五步：① 跑相关测试 → ② 提交**自己范围**的改动 → ③ 若碰过共享文件，diff 确认无吞行 → ④ 日报追加状态与待办 → ⑤ 需要交接的写成交接卡（见 P1-2）。
- **为什么**：直击 #2 #3。两次音频总线事故与代提交都是"边界没写下来"的成本。
- **落地**：本节内容回填 `开发环境.md`"分工约定"节，成为所有会话开工即读的约定。

### P1-2 交接卡模板（替代散文需求单）

- **做什么**：固定五字段——目标会话 / 任务 / 输入（拍板项与文档链接）/ 验收标准 / 涉及文件。写在日报"待办"节或独立 `docs/交接/` 卡片皆可，但字段固定。
- **为什么**：#5。装备系统 E1~E3"实装交其他会话"是下一个交接场景，正好用它试点。

### P1-3 拍板索引（一页总账）

- **做什么**：新增 `docs/拍板索引.md`：一行一条 = 日期 / 主题 / 结论一句话 / 详情链接。拍板落笔时随手登记；存量拍板（纪事 §3 + 各文档拍板节）一次性补录。
- **为什么**：#6。新会话先读一页索引，不再"重新提案已拍板事项"，也不必跨四份文档考古。

### P2（按需）

1. **归档半自动化**：把整理会话"从 Harness 本地会话文件提取对话"的逻辑固化成 `tools/archive_session.py`（已证明可行，只是没固化）。Hindsight 修好后此任务优先级自动下降——记忆库已自动留存，归档只剩"挑重点"。
2. **推送兜底**：`tools/push_retry.ps1`——push 失败自动重试 3 次（502 闪断），失败则打印"本地领先 N 提交"提醒；日报收尾检查一次 `origin/main..HEAD` 计数。
3. **截屏钩子统一**：各场景 capture 钩子收敛为一个约定旗标 `-- --capture`（场景内自行实现细节），迁移期在 `开发环境.md` 标注旧旗标。做完 P0-2 后此项紧迫性低。
