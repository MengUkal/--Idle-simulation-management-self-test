# 装备内容包 · 部位装备与词条创作 v2

> v2 拓宽（2026-10-11）：①基础件从 L1/L3/L5 三级扩为 **L1~L5 五级**（对应五层，75 → 125 件）；②新增**品级机制**（粗品/普通/精良/史诗 四档 + 传奇 + 太古）；③传奇扩至 **15 件**（+3 祖品）；④分解/洗练预留。
> 依据：设计文档 §15（22 项拍板 + 类型限制矩阵）+ [装备系统规划.md](<装备系统规划.md>)。
> 命名审定（第十一轮）：词条"掮客"、9 件传奇专名、层守机制名保留（圣经 §0 第十一轮）。
> **v2 批次已拍板（2026-10-11，第十二轮）**。

## 0. 品级机制（新增，提案）

| 品级 | 名称 | 词条栏 | 基准权重（一层 → 五层线性上移） | 色标（UI 提案） |
| --- | --- | --- | --- | --- |
| 0 | **粗品** | 0（白板） | 45% → 5% | 白 |
| 1 | **普通** | 1 | 40% → 25% | 蓝 |
| 2 | **精良** | 2 | 12% → 40% | 紫 |
| 3 | **史诗** | 3 | 3% → 30% | 金 |

规则：

1. **品级决定词条栏数量**，词条内容仍按 §1 词条池独立 roll（T1~T5）；
2. **传奇**独立掉落（不占品级 roll，见 §3），固定 3 词条 + 祖品特效；
3. **太古**不变：任意掉落 8% 为太古形态（词条数值 ×1.5，显示 T5+，专属音效+光柱），只能发现不能洗出；
4. **重生加成（提案）**：每轮重生，精良+史诗合计权重 +2%（有上限 60%），给长线成长留钩子；
5. **分解预留（E2）**：粗品/普通分解得**树胶**（洗练货币）；精良/史诗分解得**元素精华**（与现有货币打通）；
6. **存档 v6 增补**：装备实例加 `quality` 字段（0~3）；分解/洗练记录同 v1 §5。

## 4. E2 传奇规则词条预留（**仅存目，E1 不实装、未拍板**）

规则改写类传奇词条的候选方向（供 E2 设计问答用）：①魔力鸟消除改为"清除全场弱点色"；②消除弱点色时 15% 概率不消耗步数；③交易标的价格波动 +50% 且手续费减半；④每场首波消除伤害翻倍；⑤训练线 25 级后升级费用减半；⑥洗练系统（树胶重 roll 词条档位）。实现均需动棋盘/战斗/交易所接口，届时单独走问答。

## 5. 给实装会话的接口备忘

1. **新增 Mods 键**：`drop_rate`（MULT，默认 1.0）——唯一需要动 `mods.gd` 键表的地方；战斗掉落概率 = 基础概率 × `Mods.mult("drop_rate")`。
2. **词条即数据**：全部词条= `{id, name, key, kind, tiers:[5 值], slots:[...]}`，与 talents/paragon 同构，Mods 装备来源段照巅峰段落写法追加。
3. **复合词条**：`effects: [{key,kind,per}, ...]` 数组，Mods 聚合循环两行改动。
4. **品级即数据**：装备实例加 `quality: 0~3` 字段（存档 v6）；掉落时先 roll 品级（权重表按楼层插值+重生加成），再按品级词条栏数 roll 词条。
5. **数值验证**：史诗满配（10 件 × 3 词条）战斗侧理论峰值 ≈ 消除伤害 +36% + 弱点 +18% + 步数 +8——必须过 sim_test 击杀带宽验收（6~8/8），超标先砍 T5 档；品级权重表进 balance.gd 数据段。
6. **存档 v6**：背包（≤30 件实例：基础件 id + 品质 + 词条 roll 结果数组 + 太古标记 + 洗练记录）+ 穿戴 10 槽；旧档（v5）缺省空背包兼容。
