### 1.3 roll 与太古

- 每条词条独立 roll T1~T5（均匀 20%/档起步，权重可调）。
- **太古**：任一词条掉落时 8% 概率为太古形态（数值 ×1.5，T 档显示为 T5+）；只能发现，洗练不可产生；专属音效+光柱。

## 5. 给实装会话的接口备忘

1. **新增 Mods 键**：`drop_rate`（MULT，默认 1.0）——唯一需要动 `mods.gd` 键表的地方；战斗掉落概率 = 基础概率 × `Mods.mult("drop_rate")`。
2. **词条即数据**：全部词条= `{id, name, key, kind, tiers:[5 值], slots:[...]}`，与 talents/paragon 同构，Mods 装备来源段照巅峰段落写法追加。
3. **复合词条**：`effects: [{key,kind,per}, ...]` 数组（词条→多效果），Mods 聚合循环两行改动。
4. **数值验证**：满套（10 件 × 3 词条）战斗侧理论峰值 ≈ 消除伤害 +36%（主手/副手/戒指锋锐 T5）+ 弱点 +18% + 步数 +8（鞋+巅峰+天赋）——必须过 sim_test 击杀带宽验收（6~8/8），超标先砍 T5 档。
5. **存档 v6**：背包（≤30 件实例：基础件 id + 品质 + 词条 roll 结果数组 + 太古标记 + 洗练记录）+ 穿戴 10 槽；旧档（v5）缺省空背包兼容。
