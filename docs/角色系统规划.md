## 2. 设计输入与边界

- **世界观（轻背景板宪法）**：机制归玩法文档；职业/种族的**命名与文案**最终按圣经风格（北欧+黑色幽默）由世界观线审定。本文档的机制名（战士/法师…）为通用占位。
- **数值杠杆盘点**（职业/种族效果只能从这些既有杠杆里取，不加新机制）：
  挂机收入 / 献金费用 / 消除伤害 / 弱点倍率 / 连锁加成 / 步数 / 赏金 / 精华获取 / 训练费用 / 交易所手续费 / 果实获取（预留）。
- **与重生体系的关系（提案）**：职业与种族**永久保留，重生不重置**（重生重置的是"轮次进度"，不是"你是谁"）；天赋点**保留**（天赋是角色纵深）。待拍板（§9-D4）。
- **与并行会话**：角色创建流衔接标题画面会话的 `title.tscn`；种族命名对齐世界观会话。

## 3. 修饰符架构（技术核心）

所有职业/种族/天赋/被动效果统一走一个 **Mods 查询层**（`autoload/mods.gd`）：

- 杠杆点清单（现网代码改造点，每处一行改动）：

| 杠杆 | 现网位置 | 形式 |
| --- | --- | --- |
| 消除伤害 | battle.gd `_apply_damage` atk_mult | 乘 `Mods.mult("battle_damage")` |
| 弱点倍率 | battle.gd damage_multiplier 结果 | 乘 `Mods.mult("weakness_mult")` |
| 连锁加成 | Balance.CHAIN_BONUS_PER_WAVE 使用点 | 加 `Mods.add("chain_bonus")` |
| 步数 | Balance.battle_steps 结果 | 加 `Mods.add("steps")` |
| 挂机收入 | GameState.income_per_sec | 乘 `Mods.mult("income")` |
| 献金费用 | upgrade_cost 使用点 | 乘 `Mods.mult("upgrade_cost")` |
| 训练费用 | train_cost 使用点（×果实折扣处再乘） | 乘 `Mods.mult("train_cost")` |
| 赏金 | bounty 结算 | 乘 `Mods.mult("bounty")` |
| 精华获取 | EP 结算 | 乘 `Mods.mult("ep")` |
| 交易所手续费 | Balance.MARKET_FEE_RATE 使用点 | 加 `Mods.add("fee")` |
| 果实获取 | Balance.fruits_for_level 结果 | 乘 `Mods.mult("fruit")`（本期恒 1，预留） |

- Mods 在**角色创建 / 重生 / 天赋变更**三个时机重算；`mult` 类连乘、`add` 类累加，来源记录在表里（模拟器与平衡表可直接输出各职业面板）。
- 好处：天赋树/被动上线时只是"新增来源"，杠杆点零改动。

## 6. 天赋树（✅ 二期已实装，2026-10-11）

> **蓝本拍板（T1~T6 问答）**：D4 经典被动树（1.0）而非 3.0 技能分支；每职业一树；普通+重点+关键三层节点；层圈门槛；D4 式洗点；含关键天赋。
> **追加拍板**：预留**巅峰系统**——Lv.60 起每级技能点分流为巅峰点（`paragon_points`），巅峰板块后续版本开放。

- **树结构（每职业一棵，结构同构数值定制）**：
  - 圈 1：普通节点 ×3（rank 0~5，效果递增，1 点/级）
  - 圈 2：普通节点 ×3（rank 5）
  - 圈 3：**重点节点** ×1（rank 0~3，大幅效果）
  - 圈 4：**关键天赋**三选一（rank 1，流派定义；部分带 tradeoff 副作用，经隐藏副节点同步结算）
- **层圈门槛**：进入圈 2/3/4 需树上已投入 ≥ 3/12/25 点（`TREE_GATE`）。
- **洗点**：单点退还免费；整树重置收吉尔 = 已投入 × 50 G（D4 式）。
- **点数分流**：`PARAGON_LEVEL = 60`，Lv.60 前每级 +1 技能点、之后 +1 巅峰点。
- **定义表**：`data/talents.gd`（7 树 × 12~13 节点）；`GameTalents.get_node_def()` 供修饰符层查询。
- **测试**：`talent_test`——表完整性/层圈拦截/满级上限/关键互斥/tradeoff 副作用/单点退还/整树洗点/点数分流/面板构建。

## 7. 主动技能（✅ 三期已实装，2026-10-11）

> **拍板（S1~S3）**：七职业专属技能表通过；资源模型**多样化**（充能/固定次数/代价三种，按职业风味分配——用户追加）；技能消除走**正常伤害结算**（S3）。
> **设计灵感**：开心消消乐（刷新/强制交换/魔法棒/小木锤/加 5 步）+ Candy Crush（棒棒糖锤/彩糖变色）+ Royal Match（火箭清行列）+ 智龙迷城（转珠/增伤）。

| 职业 | 技能 | 效果 | 资源模型 |
| --- | --- | --- | --- |
| ⚔️ 战士 | 破城锤 | 摧毁目标十字 5 块 | ⚡充能：8 块/格，上限 3 |
| 🔮 法师 | 元素嬗变 | 随机 6 块变为怪物弱点属性 | ⚡充能：6 块/格，上限 3 |
| 🗡️ 盗贼 | 偷天换日 | 重排全盘棋子 | 🎫固定：1 次/场 |
| ✨ 牧师 | 圣光祈祷 | 步数 +3 | 🎫固定：2 次/场 |
| 🛡️ 圣骑士 | 祝圣之槌 | 目标块变爆炸特殊块 | ⚡充能：10 块/格，上限 2 |
| 🏹 游侠 | 穿透箭 | 清除目标一整列（触发掉落连锁） | ⚡充能：8 块/格，上限 2 |
| 😈 术士 | 暗影瘟疫 | 约半场方块随机变色 | 🩸代价：消耗 2 步 |

- **定义表**：`data/skills.gd`；**棋盘 API**：`match3_board.gd` skill_smash / skill_pierce_col / skill_transform_random / skill_shuffle / skill_bless / skill_plague（均走正常重力+连锁结算）。
- **战斗集成**：消除积能（charge 型）/ 每场次数（fixed）/ 步数代价（steps）；需要目标的技能走**瞄准模式**（点技能键进入、点棋盘执行、再按取消）；技能消除走正常伤害+分波动画。
- **测试**：`skills_test` 16 项断言（棋盘 API + 资源模型表）。

## 8. 被动技能（预留设计）

- **定义表结构**：`{id, trigger(如 on_clear_element), element, effect(mult/add)}`——"消除特定属性有更好伤害"即**元素亲和**（例：火之亲和=火块伤害 ×1.5）。
- **架构统一**：职业/种族特性 = 常驻被动，本期就用同一修饰符框架结算；后续"可选择的被动槽"只是把部分被动从常驻改为装配式。
- **本期范围**：定义表 + 结算钩子位。无可选被动。
