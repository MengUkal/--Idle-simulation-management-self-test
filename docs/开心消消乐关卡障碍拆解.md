## 1. 障碍物目录（40+ 种，先照抄再归约）

来源①罗列的障碍（摘录）：传送门（入口瞬间转移到出口）、冰块（≤3 层，消其上动物连带消一层）、雪块（≤5 层）、金豆荚（掉落到底部收集，飞碟会把它吸走=失败）、礼盒（对应颜色开启）、水晶球（每次移动变色）、毛球×3（灰：覆盖+跳邻；褐：同灰但特效不灭；黑：大范围跳跃吞食，需两击）、绳子/隔板（禁相邻交换）、魔法牢笼（困住，同色消可解）、毒液（每步吞噬周边动物，**全部被吃光=失败**）、银币（挡特效穿透）、鸡窝（清除后孵小鸡，小鸡散落触发随机特效）、云层/宝石（≤3 层，通关条件）、气球（消除加步数，限时消失）、翻转石板（每 3 步翻转隐藏东西）、雪怪（消周围冰柱释放，双雪怪=全屏清理）、绿叶球（每 3 步长藤蔓阻挡下落）、蜗牛（固定阻挡）、传送带（推动其上所有物体前进）、独眼仔（消 4 次→同色 3 只变直线特效）、蜜罐（开 3 次放蜂蜜黏住动物）、魔法石（周边消 3 次激活，再消触发魔法）、萌豆（3 次消除、逐次变色、仅同色可消）、染色宝宝/染色蛋（变色/变动物）、闪电鸟（双激活清阴影区）、魔法阵（3 回合轮换元素）、星星瓶（充能满→大范围扫除）、蓄电精灵（攒能量放同色清除）、钥匙-宝箱、幽灵（旁消则上升）、太阳花（清指定瓶数→清全屏障碍）、墨鱼宝宝（聚集后游动清沿途障碍）等。

道具侧（简列）：刷新×3、小木槌×3、后退一步×5、强制交换×2、+5 步、魔法棒（动物变直线）、横/竖火箭、前置特效等。

## 2. 归约：障碍的四个压力轴（思考整理的核心）

40+ 种障碍看似繁多，全部可以归约到**四条压力轴**的组合：

| 压力轴 | 改变了什么 | 代表元素 |
| --- | --- | --- |
| **耐久**（多打几下） | 格子有了"血条"，消除从 1 次变 N 次 | 冰块/雪块/云层/蜜罐/萌豆/魔法石/荷花苞 |
| **可达性**（能不能动） | 交换与下落被封锁，步数经济被改写 | 绳子隔板/蜗牛/魔法牢笼/银币/藤蔓 |
| **信息**（能不能看清） | 颜色与身份被隐藏或漂变 | 翻转石板/树叶遮蔽/水晶球变色/魔法阵轮换 |
| **时间**（不管会变糟） | 棋盘会自行恶化，制造"必须先处理"的优先级 | 毒液扩散/章鱼产毒/绿叶球长藤/毛球跳跃 |

外加两种"正向元素"：**生成器**（鸡窝/蓄电精灵/墨鱼——棋盘有产能点，围绕它规划）与**帮手**（雪怪/星星瓶/独眼仔——可解锁的友军大招，奖励观感）。

## 3. 关卡目标类型学与出题法

- **目标五型**：清除冰块/雪块（清场型）、收集指定动物 N 只（点名型）、收集金豆荚 N 个（运送型——物体要从上流到底，**竖向特效价值被目标放大**）、达到分数（数字型）、云层/宝石（挖掘型）。
- **出题公式**：`1 个主目标 + 2~3 种障碍组合 + 异形棋盘（挖洞/缺口）+ 有限步数`；障碍不堆满，组合出题。
- **三星制**：通关之外按剩余步数给星——步数余量即操作质量分。
- **失败条件多样化**：步数耗尽 / 毒液吃光动物 / 金豆荚被飞碟吸走——压力来源不单一，每关的"死法"不同。

## 4. 与本游戏的映射（现状）

我们的战斗棋盘是 7×7 均匀格、无障碍、单目标（步数内击杀）、无星级；棋盘逻辑层（match3_board.gd）已有形状检测/特殊棋子/连锁/重力记录，扩展接口清晰。PAD 拆解已提案"Boss 改写棋盘"（妨碍珠/烟幕），本篇补充的是**关卡层视角**：目标多样性、棋盘拓扑、压力轴配比。

## 6. 明确不采用（避免重新讨论）

- **体力/关卡推进制**：我们是战斗制挂机，无关卡序列；体力是付费摩擦。
- **付费道具墙/广告复活**：单机买断形态。
- **失败即重来的强惩罚**：挂机基调下失败=无赏金+撤退（已拍板），不引入"毒液吃光=整局作废"级别的硬失败——提案 B 中"占满=败"应软化为"提前撤退结算"。
- **一次性关卡手工设计**：障碍必须参数化/随机器化（怪物表字段驱动），不做手工关卡。
